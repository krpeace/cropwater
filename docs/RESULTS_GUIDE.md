| :--- | :--- | :---: |

| [2] 증발접시 | 풍상거리(fetch) | ○ |
| [3] 작물 선택 | 작물명·시나리오 | × |
| [4] Kc 파라미터 | Kc_ini/mid/end (현지기상 보정 후 표시) | △ |

| [6] 멀칭 | 멀칭 보정계수 | ○ |

### ◆ 시트 4: 결과요약

**ETo·ETc 요약**

| 항목 | 읽는 법 |
| :--- | :--- |
| ETo_PM 기간합계 | 분석 기간 기상 에너지 합산. 연간 600~900mm가 일반적 |
| ETc_PM 기간합계 | 분석 기간 작물 물 소비량 합산 |

**물수지 요약** — 무관수(자연강우만) 가정

| 항목 | 해석 |
| :--- | :--- |
| 기간 총강수 ΣP | ASOS 관측 강수량 합계 |
| 유효강수 | 근권이 흡수한 강수량 = ΣP − ΣDP |
| 심층침투 ΣDP | 근권 아래로 손실된 양 |
| 유효강수율 (%) | 낮을수록 집중호우 손실이 큰 것 |
| 관수 필요 발생 일수 | Dr ≥ RAW인 날 수 |
| 필요 순관수량 ΣIn | 스트레스 발생일 기준 이론적 보충 필요량 |
| 필요 총관수량 ΣIg | ΣIn / Ea (손실 포함 실제 공급량) |

> ⚠️ 필요 순관수량·총관수량은 **이론적 필요량**이며 실측 관수량이 아닙니다. 무관수 가정하의 누적 부족량입니다.

### ◆ 시트 5: 물수지

일별 관수 필요 시점을 확인하는 핵심 시트입니다.

| 열 | 내용 | 판단 기준 |
| :--- | :--- | :--- |
| 강수P | 당일 강수량 (mm) | |
| Dr,i-1 | 전일 말 근권 고갈량 | |
| DP | 심층침투량 = max(P − ETc_adj − Dr,i-1, 0) (FAO-56 식88 원식) | P > Dr,i-1 + 당일 ETc_adj이면 발생. 이때 Dr,i = 0 |
| Dr비후 | 강수 후 고갈량 = max(Dr,i-1 − P, 0) | Ks를 이 값으로 판단 |
| **Ks** | **수분스트레스계수** | **1.0=무스트레스, <1.0=스트레스** |
| ETc_adj | 스트레스 보정 후 실제 증발산량 | Ks × ETc |
| **Dr,i** | **당일 말 근권 고갈량** | **RAW 미만=안전, 초과=관수 필요** |
| **관수 필요** | **● 표시** | **Dr,i ≥ RAW** |
| 필요 순관수량 In | 당일 이론적 관수 필요량 | ● 인 날만 표시 |
| 필요 총관수량 Ig | In / Ea | ● 인 날만 표시 |

**색상 의미**

| 색상 | 조건 | 의미 |
| :--- | :--- | :--- |
| 🔴 빨간 배경 | Dr ≥ RAW | 관수 필요 |
| 흰 배경 | Dr < RAW | 정상 |

연속 ● 구간은 무관수 상태에서 Dr이 누적되는 구간입니다. 관수를 했다면 실제 Dr은 이보다 낮습니다.

### ◆ 시트 4: 관수필요_달력

지점 간 비교에서 가장 직관적인 시트입니다.

**히트맵 (상단)** — 셀 숫자 = Dr (mm)

| 색상 | Dr 범위 | 의미 |
| :--- | :--- | :--- |
| 흰색 | Dr ≈ 0 | 포장용수량에 가까운 상태 |
| 연녹 | 0 < Dr < RAW×0.5 | 안전 |
| 연노 | RAW×0.5 ≤ Dr < RAW | 주의 (관수 계획 시작) |
| 연주황~연적 | RAW ≤ Dr < TAW×0.6 | 관수 필요 |
| 진적 (굵은 글씨) | Dr ≥ TAW×0.6 | 심각한 스트레스 |
| 회색 | — | 데이터 결측 |

**Dr 선형 차트 (하단)**
- 실선: 각 지점의 Dr 추이
- 빨간 점선: RAW (관수 트리거 라인)
- Dr이 점선을 위로 넘어서는 날 = 관수 필요 시점

## cropwater_fcst.py verify 결과 — 단기예보 H2 검증 (11시트 + 하늘상태가 있으면 SKY계수, --compare면 격자비교)

> 02-Cycle 가설검증용입니다. 과거 단기예보로 만든 예보 ETo·ETc를 ASOS 관측값과 비교해, 예보를 관수 판단에 쓸 만한지(H2) 판정합니다. 이론은 [THEORY.md 9장](THEORY.md#9-예보-기반-etoetc--기상청-단기예보)에 있습니다.

**노란 칸**(요약의 합격 기준, 설정, Rs계수, SKY계수, 월별 선행일)을 바꾸면 다시 계산됩니다. 오차분해·격자비교 시트만 Python 계산값이라 다시 계산되지 않습니다.

**주 방법(★)**: 하늘상태(SKY) 예보가 들어 있으면 S4(하늘상태 반영), 없으면 S3입니다. 요약 시트 'Rs 추정' 행과 표 제목에 표시됩니다.

### ◆ 시트 1: 요약

| 영역 | 읽는 법 |
| :--- | :--- |
| 자료 정보 | 예보 격자·발표 수(6요소가 모두 있는 발표와 빠진 발표), 서비스 발표 수, 대상일, 관측 기준, Rs 계수, Kc |
| 제외 | 자료 공백으로 뺀 서비스 발표 구간(요소가 하나라도 빠진 발표)과 뺀 행의 사유(예: 대상일 관측 없음). 공백이 없으면 이 행이 없습니다 |
| H2 합격 기준 | 개선율 기준(30%)과 D+1 RMSE 상한(1.0 mm/일). 노란 칸을 바꾸면 판정이 바뀝니다 |
| 판정 표 | 발표별 D+1~D+3 최소 개선율, D+1 RMSE, 판정(통과=녹색, 미달=적색) |
| 선행시간별 ETo·ETc 표 | n, 관측·예보 평균, MBE, RMSE, R², 지속성·7일평균 RMSE와 개선율. 'H2 판정 대상' ○ = D+1~D+3 |
| Rs 방법 비교 (S4일 때) | 같은 대상일에서 S4·S3·S1의 RMSE, 'S4 − S3'(녹색 = S4가 나음, 적색 = 나쁨), 개선율, MBE |
| 3일 누적 | 발표별 첫 3개 대상일 합(아침 D+0~D+2, 저녁 D+1~D+3). 상대 RMSE = RMSE ÷ 관측 3일합 평균 |
| 주요 발견 | ①~③은 셀과 연결된 수식 문장. ④ 이후는 Python 분석: 판정 불확실성 → 월별 약점 → 오차 원인 → 보정 탐색 → 격자·자료 조건 경고 |
| 차트 | 선행시간별 RMSE(예보·지속성·7일평균), 관측 ETo와 D+1 예보 시계열 |

- **개선율**: 1 − RMSE_예보 ÷ RMSE_기준선. 50%면 오차가 기준선의 절반입니다.
- **MBE가 음수**면 예보가 관측보다 작습니다(과소추정). 물수지에서는 고갈량(Dr)이 실제보다 천천히 늘어 관수 필요일을 늦게 알립니다.

### ◆ 시트 2: 일별비교

발표 × 대상일 한 행(아침 4일 + 저녁 4일 × 발표 수). 열 묶음은 1행 머리글에 표시됩니다.

| 열 | 내용 |
| :--- | :--- |
| A~F | 발표번호, 구분(아침·저녁), 발표시각, 발표일, 선행일 k, 대상일 |
| G~N | 예보 일 입력: 마지막날 여부(3시간·코드), Tmax, Tmin, ea, u10, 강수, 시각 수, 이전 발표로 채운 시각 수 |
| O~X | 강수유무, Ra, Rso, Rs(S3·S1), u2, PM 중간값 |
| **Y** | **예보 ETo (S3)** — 주 결과 |
| Z | 예보 ETo (S1, kRs 0.16) — 비교용 |
| AA~AC | 관측 ETo, 지속성(발표일 전날 관측), 7일평균(발표일 전 7일) |
| AD~AG | 오차(예보 − 관측) |
| AH~AO | Kc, 예보·관측·기준선 ETc와 오차 |
| AP~BB | 입력 진단: 관측 Tmax·Tmin·ea·u10·Rs·강수유무, 입력별 오차, 강수 판정(적중·놓침·오보·무강수 일치) |

- **하늘상태가 있으면(S4)** 열이 몇 개 늘어나 위 열 문자가 뒤로 밀립니다. 늘어나는 열: 구름많음 비율·흐림 비율·강수확률(예보 입력), S4 교차검증 묶음·S4 계수 행·★ Rs S4(Rs 묶음), ★ 예보 ETo S4(ETo 묶음), 오차 S4, Rs 오차(S3). 이때 ★ 예보 ETc와 입력 진단의 Rs 오차는 S4 기준입니다.
- 자동 필터가 걸려 있습니다. 구분·선행일로 걸러 보면 특정 선행시간의 날짜별 오차를 볼 수 있습니다.
- 'N 이전 발표로 채운 시각 수'가 8이면 00~07시를 전날 저녁 발표로 채운 것입니다(아침 D+0, 포털 자료). OpenAPI·요소별 KST 자료는 발표 1시간 뒤부터 있어 3(00~02시)입니다.

### ◆ 시트 3: 3일누적

발표 한 행. 예보·관측·지속성의 3일 합과 오차.

### ◆ 시트 4: 월별 — 생육기 안에서 어느 달이 약한가

대상일의 월로 나눈 지표입니다. 모두 일별비교 시트를 참조하는 수식이고, 노란 칸의 **선행일 k**(기본 1)를 바꾸면 ①·③이 다시 계산됩니다.

| 표 | 읽는 법 |
| :--- | :--- |
| ① 월별 성능 | 발표 × 월별 n, 관측·예보 평균, MBE, RMSE, 상대 RMSE(= RMSE ÷ 관측 평균), 지속성·7일평균 RMSE와 개선율. 붉은 칸 = 선행일 1의 RMSE가 기준보다 크거나, 선행일 1~3의 개선율이 기준보다 작은 달 |
| ② 달마다 기준 적용 (참고) | 달마다 D+1~D+3 개선율, 최소 개선율, D+1 RMSE와 충족 여부. **원인 진단용**이며 H2 판정은 요약 시트(전체 기간)입니다 |
| ③ 월별 입력 편향 | 예보 − 관측: Tmax, Tmin, 일교차, ea, u10, 추정 Rs. 예보·관측 강수일 비율, 오보·놓침 일수 |
| 차트 | 월별 RMSE (선행일 k, 아침·저녁) |

- 기준(개선율·D+1 RMSE)은 요약 시트의 노란 칸을 따라갑니다.
- **Rs 편향**을 Rs계수 시트의 월별 표(관측 입력으로 추정한 Rs의 편향)와 비교하면 원인을 나눌 수 있습니다.
  - 두 값이 비슷하면 추정식 자체의 한계, 예보 입력 쪽이 훨씬 작으면 예보 입력(일교차·강수유무) 탓입니다.
- 예보 강수일 비율이 관측보다 크면(오보가 많으면) 강수유무 보정 때문에 Rs와 ETo가 과소추정됩니다.
- 예) 2026년 춘천: 6~8월 D+1 RMSE 1.0~1.2 mm/일. 6월은 예보 일교차, 7월은 비 예보 과다(70% vs 43~47%), 8월은 추정식 자체(관측 입력으로도 Rs −1.5 MJ/m²/일)

### ◆ 시트 5: 입력진단

발표 × 선행일별 입력 편향(예보 − 관측)과 RMSE, 강수유무 적중표(POD·FAR·CSI).

- 예보 최고·최저기온(TMX 09~18시, TMN 03~09시)과 ASOS 일최고·최저(0~24시)는 정의가 달라 편향의 일부가 정의 차이입니다.
- 아침 D+k와 전날 저녁 D+(k+1)은 같은 대상일입니다. 최고·최저기온 예보가 17시 이후 발표에서 잘 바뀌지 않아 두 발표의 기온 진단이 거의 같습니다.

### ◆ 시트 6: 오차분해 (Python 계산값)

| 표 | 읽는 법 |
| :--- | :--- |
| ① 입력 교체 | 예보 입력을 하나씩 관측값으로 바꿨을 때의 RMSE. 가장 많이 줄어드는 입력이 오차의 주원인 |
| ② 보정 탐색 | 다른 달 자료로 보정값을 추정해 적용했을 때의 성능(월 단위 교차검증). 기온 / 기온+풍속 / ETo 비율 / Rs 계수 재보정(예보 일교차·강수유무로 Rs 식 계수를 다시 맞춤). H2 판정에는 쓰지 않음 |
| ③ 입력 편향 | 전체 기간 평균 편향 = 보정값의 크기 |
| ④ 판정 불확실성 | 7일 블록 부트스트랩 2,000회: D+1 RMSE·최소 개선율의 90% 구간(5~95 백분위)과 **두 기준 충족 비율**. 보정 없음(판정 기준)과 ②의 보정을 적용한 경우(탐색) |

- **두 기준 충족 비율**이 90%보다 낮으면, 점추정이 통과해도 기준과의 여유가 표본 변동보다 작다는 뜻입니다. 다른 해에는 미달할 수 있습니다.
  - 예) 2026년 춘천 아침 발표 67%(D+1 RMSE 0.97), 저녁 발표 100%(0.86). 교차검증한 보정을 적용하면 아침 97%
  - 예) 2025년 춘천(2026년 S4 계수 고정): 아침 44%(최소 개선율 32%, D+3), 저녁 98%. 점추정은 통과했지만 아침은 다른 해에 미달할 수 있는 여유입니다

### ◆ (선택) 격자비교 — `--compare`로 다른 격자 예보를 함께 넣었을 때

같은 관측·Rs 계수·Kc로 두 격자의 예보를 계산해 비교합니다. 차이는 모두 예보 격자에서 옵니다.

| 표 | 읽는 법 |
| :--- | :--- |
| ① 선행시간별 성능 | 두 격자의 MBE·RMSE·개선율. 'RMSE 차이 A−B'가 음수면 이 검증의 격자(A)가 더 좋음 |
| ② 입력 편향 | 두 격자의 최고·최저기온·풍속 편향(예보 − 관측) |
| ③ 직접 차이 | 같은 발표·선행일끼리 A − B의 평균·표준편차, 강수유무 일치율 |
| ④ 월별 직접 차이 | 격자 차이가 계절에 따라 달라지는지 |

- 예) 춘천: 73_134(ASOS 101 격자) − 73_135(신북읍) 최고기온 +1.1℃, 예보 ETo +0.16 mm/일 (2026년 4~6월)

### ◆ (하늘상태가 있을 때) SKY계수 — S4 계수

| 표 | 읽는 법 |
| :--- | :--- |
| ① 검증용 계수 | 교차검증 묶음(대상월) × 선행일마다 a~e. 그 달을 뺀 나머지 달로 맞춘 값이며, 일별비교가 '묶음\|선행일' 키로 찾아 씁니다(노란 칸) |
| ② 운영 계수 | 자료 전체로 선행일마다 맞춘 값(rs_sky_coef.csv). 같은 자료로 맞춘 값이라 검증에는 쓰지 않습니다 |

- **다른 해 독립 검증(`verify --s4-coef`)일 때**는 두 표의 뜻이 바뀝니다. 제목 줄에 '다른 해 독립 검증'이 붙습니다.
  - ① 검증용 계수 = 다른 해의 운영 계수를 그대로 쓴 값입니다. 묶음 이름은 '고정'이고 키는 '고정\|선행일'입니다. '적합 행 수'는 원래 해의 행 수입니다.
  - ② = 검증 연도 자료로 맞춘 계수(참고)입니다. ①과 비교하면 계수가 해마다 얼마나 달라지는지 알 수 있습니다.

- Rs/Ra = a + b·√(Tmax−Tmin) + c·강수유무 + d·구름많음 비율 + e·흐림 비율
- d·e가 음수 = 구름이 많을수록 Rs가 줄어듦. D+0에서 D+3으로 갈수록 흐림 계수(e)의 크기가 줄고 강수유무 계수(c)의 크기가 커집니다(D+4는 D+3과 비슷). 먼 날의 하늘상태 예보는 덜 믿을 만하다는 뜻입니다.
- 예) 춘천 2026 운영 계수: 흐림 계수 −0.25(D+0) → −0.15(D+3)

### ◆ 시트 7: Rs계수 / 시트 8: 관측 / 시트 9: 설정

- **Rs계수**: S3 계수 a·b·c와 지점 kRs(노란 칸), 보정 자료 기간. 아래 표는 H1 재검증(관측 입력 + Rs만 추정) 결과와 월별 편향(ETo와 Rs)입니다. 계수를 바꾸면 예보 ETo까지 모두 다시 계산됩니다.
  - H1 기간은 생육 시작일부터 9/30까지입니다(관측이 그 전에 끝나면 관측 마지막 날).
  - 관측 결측일(기온·풍속·일사·습도 중 하나라도 없음)은 H1 표와 월별 표에서 뺍니다. 예) 2025년 6/5~6/7
- **관측**: ASOS 일자료(값)와 관측 ETo·Kc·ETc·직전 7일 평균(수식). 관측 ETo는 01-Cycle 계산과정 시트와 같은 값입니다.
- **설정**: 지점 위도·고도·풍속계 높이, 예보 풍속 높이, 예보 기압(식7), 강수유무 기준, Kc 파라미터(01-Cycle 워크북 값).

### ◆ 시트 10: 방법 / 시트 11: 차트자료

- **방법**: 자료, 일 입력 만들기(지나간 시각 채움, 결측 규칙, 마지막 날 코드 변환), 기준선, 지표(월별·불확실성 포함), 판정, 한계(격자·기간·연도·강수).
- **차트자료**: 요약 시트 시계열 차트의 원본(대상일별 관측 ETo, 아침·저녁 D+1 예보).
