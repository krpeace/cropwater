## cropwater_station.py 결과 (6시트)

### ◆ 시트 1: 설정

프로그램이 사용한 모든 파라미터가 표시됩니다. **노란 셀**은 직접 편집 가능하며, 값을 바꾸면 계산과정·결과요약·물수지 시트가 자동 재계산됩니다.

| 섹션 | 주요 항목 | 편집 |
| :--- | :--- | :---: |
| [1] 지점 정보 | 위도·고도·풍속계높이 | △ |
| [2] 증발접시 | 풍상거리(fetch) | ○ |
| [3] 작물 선택 | 작물명·시나리오 | × |
| [4] Kc 파라미터 | Kc_ini/mid/end (현지기상 보정 후 표시) | △ |
| [5] 생육단계 | 발아일·L_ini/dev/mid/late | ○ |
| [6] 멀칭 | 멀칭 보정계수 | ○ |
| [7] 생육기간 | 중기·후기 시작/종료일 (자동 계산) | × |
| **[8] 토양·근권** | **θFC·θWP·Zr·p·TAW·RAW·Dr₀·Ea** | **○** |

> TAW·RAW는 [8] 섹션에서 자동 계산됩니다. θFC·θWP·Zr 변경 시 즉시 반영됩니다.

### ◆ 시트 2: 원데이터

기상청 ASOS 일별 원자료 그대로입니다. 이 시트는 수정하지 마세요.

| 결측 항목 | 처리 |
| :--- | :--- |
| `sumGsr` (일사량) | 일조시간(`sumSsHr`)으로 Ångström 공식 추정 |
| 날짜가 빠진 날, 또는 ETo 필수 입력(최고·최저기온, 풍속, 습도, 일사·일조)이 빈 날 | **'결측'** 표시(O열, 분홍 칸). 빠진 날짜는 행을 넣음. 그날 ETo = 앞 7일 ETo 평균(계산과정 U열), 강수는 관측값이 없으면 0 → 물수지가 끊기지 않고 이어짐. 결과요약에 결측일 수 (#20) |

- 예) 2025년 춘천: 6/5·6/7은 관측 빈 칸, 6/6은 행 없음 → 세 날 ETo 4.0·4.0·3.9 mm(이전에는 빈 칸을 0으로 계산해 1.4·—·1.2 mm). 관수 필요 일수 22 → 24일

### ◆ 시트 4: 결과요약

**ETo·ETc 요약**

| 항목 | 읽는 법 |
| :--- | :--- |
| ETo_PM 기간합계 | 분석 기간 기상 에너지 합산. 연간 600~900mm가 일반적 |
| ETc_PM 기간합계 | 분석 기간 작물 물 소비량 합산 |

**물수지 요약** — 강우 + 물수지 시트 I열의 관수량(비어 있으면 무관수)

| 항목 | 해석 |
| :--- | :--- |
| 기간 총강수 ΣP | ASOS 관측 강수량 합계 |
| 유효강수 | 근권이 흡수한 강수량 = ΣP − ΣDP. 관수를 입력하면 '—'(심층침투가 비와 관수 중 어디서 왔는지 나눌 수 없음) |
| 심층침투 ΣDP | 근권 아래로 손실된 양(비·관수) |
| 유효강수율 (%) | 낮을수록 집중호우 손실이 큰 것. 관수를 입력하면 '—' |
| 관수 필요 발생 일수 | Dr ≥ RAW인 날 수 |
| 필요 순관수량 ΣIn | ● 날의 Dr 합(그날 포장용수량까지 채우는 이론적 양) |
| 필요 총관수량 ΣIg | ΣIn / Ea (손실 포함 실제 공급량) |
| 입력 관수량 합계 ΣI | 물수지 시트 I열에 넣은 공급량 합계 |

> ⚠️ 필요 순관수량·총관수량은 **이론적 필요량**입니다. 관수 기록을 넣지 않았으면 무관수 가정하의 누적 부족량입니다.

### ◆ 시트 5: 물수지

일별 관수 필요 시점을 확인하는 핵심 시트입니다.

| 열 | 내용 | 판단 기준 |
| :--- | :--- | :--- |
| 강수P | 당일 강수량 (mm) | |
| Dr,i-1 | 전일 말 근권 고갈량 | Ks를 이 값으로 판단(FAO-56 원식, 2026-09-30) |
| DP | 심층침투량 = max(P + I·Ea − ETc_adj − Dr,i-1, 0) (FAO-56 식88 원식) | 비·관수가 Dr,i-1 + 당일 ETc_adj보다 많으면 발생. 이때 Dr,i = 0 |
| **관수량 I (노란 칸)** | **실제로 준 관수량(공급량, mm). 10a당 1톤 = 1 mm** | `--irrig 관수기록.csv`로 채우거나 직접 입력. 근권에는 × Ea |
| **Ks** | **수분스트레스계수** | **1.0=무스트레스, <1.0=스트레스** |
| ETc_adj | 스트레스 보정 후 실제 증발산량 | Ks × ETc |
| **Dr,i** | **당일 말 근권 고갈량** | **RAW 미만=안전, 초과=관수 필요** |
| **관수 필요** | **● 표시** | **Dr,i ≥ RAW** |
| 필요 순관수량 In | 당일 이론적 관수 필요량 | ● 인 날만 표시 |
| 필요 총관수량 Ig | In / Ea | ● 인 날만 표시 |

**색상 의미**

| 색상 | 조건 | 의미 |
| :--- | :--- | :--- |
| 🔴 빨간 배경 | Dr ≥ RAW | 관수 필요 |
| 흰 배경 | Dr < RAW | 정상 |

연속 ● 구간은 관수하지 않은 상태에서 Dr이 누적되는 구간입니다. 실제로 관수했다면 I열에 적으세요. Dr이 줄고 다음 ●가 뒤로 밀립니다.

| 컬럼 | 해석 |
| :--- | :--- |

| 색상 | Dr 범위 | 의미 |
| :--- | :--- | :--- |
| 흰색 | Dr ≈ 0 | 포장용수량에 가까운 상태 |
| 연녹 | 0 < Dr < RAW×0.5 | 안전 |

## cropwater_fcst.py verify 결과 — 단기예보 H2 검증 (11시트 + 하늘상태가 있으면 SKY계수, --compare면 격자비교)

> 02-Cycle 가설검증용입니다. 과거 단기예보로 만든 예보 ETo·ETc를 ASOS 관측값과 비교해, 예보를 관수 판단에 쓸 만한지(H2) 판정합니다. 이론은 [THEORY.md 9장](THEORY.md#9-예보-기반-etoetc--기상청-단기예보)에 있습니다.

**노란 칸**(요약의 합격 기준, 설정, Rs계수, SKY계수, 월별 선행일)을 바꾸면 다시 계산됩니다. 오차분해·격자비교 시트만 Python 계산값이라 다시 계산되지 않습니다.

**주 방법(★)**: 하늘상태(SKY)·강수확률(POP) 예보가 들어 있으면 S4(하늘상태·강수확률 반영), 없으면 S3입니다. 요약 시트 'Rs 추정' 행과 표 제목에 표시됩니다.

### ◆ 시트 1: 요약

| 영역 | 읽는 법 |
| :--- | :--- |
| 자료 정보 | 예보 격자·발표 수(6요소가 모두 있는 발표와 빠진 발표), 서비스 발표 수, 대상일, 관측 기준, Rs 계수, Kc |
| 제외 | 자료 공백으로 뺀 서비스 발표 구간(요소가 하나라도 빠진 발표)과 뺀 행의 사유(예: 대상일 관측 없음). 공백이 없으면 이 행이 없습니다 |
| H2 합격 기준 | 개선율 기준(30%)과 D+1 RMSE 상한(1.0 mm/일). 노란 칸을 바꾸면 판정이 바뀝니다 |
| 판정 표 | 발표별 D+1~D+3 최소 개선율, D+1 RMSE, 판정(통과=녹색, 미달=적색) |
| 선행시간별 ETo·ETc 표 | n, 관측·예보 평균, MBE, RMSE, R², 지속성·7일평균 RMSE와 개선율. 'H2 판정 대상' ○ = D+1~D+3 |
| Rs 방법 비교 (S4일 때) | 같은 대상일에서 S4·S3·S1의 RMSE, 'S4 − S3'(녹색 = S4가 나음, 적색 = 나쁨), 개선율, MBE |
| 3일 누적 | 발표별 첫 3개 대상일 합(아침 D+0~D+2, 저녁 D+1~D+3). 상대 RMSE = RMSE ÷ 관측 3일합 평균 |
| 주요 발견 | ①~③은 셀과 연결된 수식 문장. ④ 이후는 Python 분석: 판정 불확실성 → 월별 약점 → 오차 원인 → 보정 탐색 → 격자·자료 조건 경고 |
| 차트 | 선행시간별 RMSE(예보·지속성·7일평균), 관측 ETo와 D+1 예보 시계열 |

- **개선율**: 1 − RMSE_예보 ÷ RMSE_기준선. 50%면 오차가 기준선의 절반입니다.
- **MBE가 음수**면 예보가 관측보다 작습니다(과소추정). 물수지에서는 고갈량(Dr)이 실제보다 천천히 늘어 관수 필요일을 늦게 알립니다.

### ◆ 시트 2: 일별비교

발표 × 대상일 한 행(아침 4일 + 저녁 4일 × 발표 수). 열 묶음은 1행 머리글에 표시됩니다.

| 열 | 내용 |
| :--- | :--- |
| A~F | 발표번호, 구분(아침·저녁), 발표시각, 발표일, 선행일 k, 대상일 |
| G~N | 예보 일 입력: 마지막날 여부(3시간·코드), Tmax, Tmin, ea, u10, 강수, 시각 수, 이전 발표로 채운 시각 수 |
| O~X | 강수유무, Ra, Rso, Rs(S3·S1), u2, PM 중간값 |
| **Y** | **예보 ETo (S3)** — 주 결과 |
| Z | 예보 ETo (S1, kRs 0.16) — 비교용 |
| AA~AC | 관측 ETo, 지속성(발표일 전날 관측), 7일평균(발표일 전 7일) |
| AD~AG | 오차(예보 − 관측) |

- **하늘상태·강수확률이 있으면(S4)** 열이 몇 개 늘어나 위 열 문자가 뒤로 밀립니다. 늘어나는 열: 구름많음 비율·흐림 비율·강수확률(낮 평균·하루 최대; 하루 최대가 S4의 강수 입력), S4 교차검증 묶음·S4 계수 행·★ Rs S4(Rs 묶음), ★ 예보 ETo S4(ETo 묶음), 오차 S4, Rs 오차(S3). 이때 ★ 예보 ETc와 입력 진단의 Rs 오차는 S4 기준입니다.
- 자동 필터가 걸려 있습니다. 구분·선행일로 걸러 보면 특정 선행시간의 날짜별 오차를 볼 수 있습니다.
- 'N 이전 발표로 채운 시각 수'가 8이면 00~07시를 전날 저녁 발표로 채운 것입니다(아침 D+0, 포털 자료). OpenAPI·요소별 KST 자료는 발표 1시간 뒤부터 있어 3(00~02시)입니다.

### ◆ 시트 4: 월별 — 생육기 안에서 어느 달이 약한가

대상일의 월로 나눈 지표입니다. 모두 일별비교 시트를 참조하는 수식이고, 노란 칸의 **선행일 k**(기본 1)를 바꾸면 ①·③이 다시 계산됩니다.

| 표 | 읽는 법 |
| :--- | :--- |
| ① 월별 성능 | 발표 × 월별 n, 관측·예보 평균, MBE, RMSE, 상대 RMSE(= RMSE ÷ 관측 평균), 지속성·7일평균 RMSE와 개선율. 붉은 칸 = 선행일 1의 RMSE가 기준보다 크거나, 선행일 1~3의 개선율이 기준보다 작은 달 |
| ② 달마다 기준 적용 (참고) | 달마다 D+1~D+3 개선율, 최소 개선율, D+1 RMSE와 충족 여부. **원인 진단용**이며 H2 판정은 요약 시트(전체 기간)입니다 |
| ③ 월별 입력 편향 | 예보 − 관측: Tmax, Tmin, 일교차, ea, u10, 추정 Rs. 예보·관측 강수일 비율, 오보·놓침 일수 |
| 차트 | 월별 RMSE (선행일 k, 아침·저녁) |

- 기준(개선율·D+1 RMSE)은 요약 시트의 노란 칸을 따라갑니다.
- **Rs 편향**을 Rs계수 시트의 월별 표(관측 입력으로 추정한 Rs의 편향)와 비교하면 원인을 나눌 수 있습니다.
  - 두 값이 비슷하면 추정식 자체의 한계, 예보 입력 쪽이 훨씬 작으면 예보 입력(일교차·강수유무) 탓입니다.
- 예보 강수일 비율이 관측보다 크면(오보가 많으면) 강수 항(S4는 강수확률, S3는 강수유무) 때문에 Rs와 ETo가 과소추정됩니다.
- 예) 2026년 춘천(S4, OpenAPI 생육기 전체): D+1 RMSE가 1.0을 넘는 달은 아침 6·7월(최대 7월 1.13 mm/일)·저녁 7월. 이 달들의 예보 Rs가 관측보다 0.9~1.8 MJ/m²/일 작고, 7월은 비 예보일이 69%(실제 45%)

### ◆ 시트 5: 입력진단

발표 × 선행일별 입력 편향(예보 − 관측)과 RMSE, 강수유무 적중표(POD·FAR·CSI).

- 예보 최고·최저기온(TMX 09~18시, TMN 03~09시)과 ASOS 일최고·최저(0~24시)는 정의가 달라 편향의 일부가 정의 차이입니다.
- 아침 D+k와 전날 저녁 D+(k+1)은 같은 대상일입니다. 최고·최저기온 예보가 17시 이후 발표에서 잘 바뀌지 않아 두 발표의 기온 진단이 거의 같습니다.

| **작물 증발산 ETc 3일 합 ± 오차** | **주 지표.** 오차 = 3일 합 × r₃(같은 달·같은 발표의 3일 누적 예보 오차 비율). 하루 값보다 믿을 만함 |
| 강수 3일 합 (기대 강수) | 예보 강수량 합과 기대 강수(강수량 × 강수확률) 합. 예보 강수량은 관측보다 많게 나오는 경향. 지난 날짜는 관측 강수 |
| **관수 필요 예상일** | 관수하지 않을 때 처음 Dr ≥ RAW가 되는 날(중심). '지금 필요'면 출발이 이미 RAW 이상 |
| 빠르면 · 늦으면 | 빠르면 = 비가 오지 않고 ETc가 오차만큼 많을 때, 늦으면 = 예보 비가 모두 오고 ETc가 오차만큼 적을 때. **비 예보가 있으면 '빠르면'을 꼭 함께 보세요**(두 해 검증에서 실제 날짜가 '빠르면'보다 앞선 적이 없음) |
| 권장 관수량 | 예상일의 중심 Dr = 포장용수량까지 채우는 순량, 공급량 = 순량 ÷ Ea(10a당 톤) |
| 날짜별 전망 | ETo·Kc·ETc ± 오차·예보 강수·강수확률·기대 강수·예상 Dr(중심)·범위(늦으면~빠르면)·상태. 마지막 날은 회색 '참고' |
| 머리 ※ 줄 (운영) | (G5) 평소와 다르게 계산했을 때만 주황 글씨: 서비스 발표를 받지 못해 직전 발표로 계산 / 하늘상태·강수확률 없음 → 일사 S3 / 어제 ASOS 관측이 아직 없음 |
| 수집 정보 (운영) | (G5, `cropwater_ops.py`로 만든 엑셀) 계산에 쓴 예보 발표(서비스 발표 또는 직전 발표), 일사 추정(S4·S3), 어제 관측(ASOS / 예보로 진행), 대상일 수, 만든 시각 |

- **날짜 선택:**
  - 지난 날짜를 고르면 관측 물수지 결과입니다. 실제 비와 관수 기록(노란 칸)이 들어간 값이라 '관수하지 않으면'이 아니고, ± 오차와 범위는 없습니다('(관측값)').
  - 3일 창이 발표일을 넘으면 넘는 날은 이 발표의 예보입니다. 이때 3일 합 옆에 '(± 는 발표일만)'이 나옵니다.
  - 발표일 뒤 날짜는 이 발표의 예보로 진행한 값입니다. 예보가 닿지 않는 날은 '자료 없음'입니다.
  - 조회할 수 있는 날짜는 관측 물수지 둘째 날 ~ 마지막 예보 대상일입니다. 그 밖의 날짜는 전부 '자료 없음'으로 나옵니다.
  - 파일을 새로 만들면 조회일은 다시 발표일입니다(같은 슬롯을 다시 실행하면 덮어씀).
- **과습 표시:**
  - 과습 경고 = 관측 물수지의 끝 Dr이 0(0.05 mm 미만). 근권이 포장용수량까지 찬 상태라, 더 주는 물은 모두 심층침투로 빠집니다.
  - 과습 주의 = 끝 Dr이 과습 주의 기준(설정 시트 노란 칸, 기본 RAW × 10% = 6 mm) 이하.
  - 예보는 쓰지 않습니다. 조회일 전날이 예보로 진행한 날이면 과습을 판정하지 않습니다. 다만 어제 ASOS 관측이 아직 없을 때(아침 02:10)는 관측 마지막 날로 판정하고, 옆 칸에 그 날짜를 적습니다.
  - 생육기(Kc > 0)에만 판정합니다. 휴면기에는 ETc가 0이라 Dr이 계속 0이기 때문입니다.
  - 참고 지표입니다. 배수 불량·지하수위는 계산에 없고, 기준값은 토양수분 센서와 대조해 검증하지 않았습니다(VALIDATION #23).
- **직전 발표로 대신한 전망**(G5, #12): 더 멀리 내다본 예보라 ± 오차와 범위가 조금 넓습니다(대체 발표 기준 선행일의 오차). 저녁 17시 발표를 14시 발표로 대신하면 마지막 날(D+4, 참고)이 없습니다.
- **어제 관측이 아직 없을 때**(보통 아침 02:10): 두 해 검증에서 중심 예상 Dr 오차가 D+0에서 약 3.5 mm 커졌습니다. 범위(빠르면~늦으면)는 실제 관수 필요일을 모두 담았습니다([THEORY.md 9장 ◆ 전날 관측이 없을 때](THEORY.md#9-예보-기반-etoetc--기상청-단기예보)).

### ◆ 시트 2~8

- **예보 물수지:** 출발(어제 끝 관측 Dr) → (관측 전 어제) → (저녁은 오늘) → 대상일. 세 경로의 고갈량은 수식입니다. 예보 ETo·강수·r은 값(예보 ETo의 PM 계산은 H2 검증 엑셀과 같은 방법)
  - (G5) '관측 전' 행: 어제 ASOS 관측이 아직 없을 때 어제를 아침 D+0 예보로 진행하는 행(선행일 'D−1', 회색). 출발은 관측 마지막 날 끝 Dr입니다. '관측 물수지'의 어제 관수 기록(노란 칸)이 세 경로에 모두 들어가고, ASOS 행은 있고 일사만 빠진 날은 관측 강수를 씁니다('관측 강수' 표시)
- **관측 물수지:** 생육 시작 전부터 어제까지. **노란 칸(관수 기록)에 준 관수량(공급 mm)을 적으면** 어제 끝 Dr과 전망이 바로 다시 계산됩니다. 관측이 빠진 날은 그날 아침 발표 D+0 예보로 채움(노란 바탕). 어제 관측이 아직 없으면 어제 행도 예보로 채워 보이지만, 전망은 '예보 물수지'의 '관측 전' 행으로 계산합니다
- **날짜별:** 날짜 선택이 찾아오는 표. 관측 물수지(흰 바탕)와 예보 물수지(회색 바탕)를 날짜순으로 이었습니다. 오른쪽 R·S열은 찾기 칸이므로 바꾸지 않습니다
- **오차표:** ± 오차와 범위에 쓴 예보 ETo 오차(여러 해 합침)
- **편향 점검:** 월·발표·선행일별 예보 − 관측 평균(|MBE| ≥ 0.3 mm/일 노란 칸)과, 예보 자료가 있으면 이 발표 이전 최근 30일 편향. 보정은 하지 않습니다(#10)
- **설정:** 토양 값(노란 칸)을 바꾸면 TAW·RAW와 두 물수지가 다시 계산됩니다. 과습 주의 기준 Dr(기본 = RAW × 10%)도 여기서 바꿉니다
- **방법:** 계산 방법·검증·한계 요약
