### ◆ 시트 4: 결과요약

**ETo·ETc 요약**

| 항목 | 읽는 법 |
| :--- | :--- |
| ETo_PM 기간합계 | 분석 기간 기상 에너지 합산. 연간 600~900mm가 일반적 |
| ETc_PM 기간합계 | 분석 기간 작물 물 소비량 합산 |

**물수지 요약** — 무관수(자연강우만) 가정

| 항목 | 해석 |
| :--- | :--- |
| 기간 총강수 ΣP | ASOS 관측 강수량 합계 |
| 유효강수 | 근권이 흡수한 강수량 = ΣP − ΣDP |
| 심층침투 ΣDP | 근권 아래로 손실된 양 |
| 유효강수율 (%) | 낮을수록 집중호우 손실이 큰 것 |
| 관수 필요 발생 일수 | Dr ≥ RAW인 날 수 |
| 필요 순관수량 ΣIn | 스트레스 발생일 기준 이론적 보충 필요량 |
| 필요 총관수량 ΣIg | ΣIn / Ea (손실 포함 실제 공급량) |

> ⚠️ 필요 순관수량·총관수량은 **이론적 필요량**이며 실측 관수량이 아닙니다. 무관수 가정하의 누적 부족량입니다.

### ◆ 시트 5: 물수지

일별 관수 필요 시점을 확인하는 핵심 시트입니다.

| 열 | 내용 | 판단 기준 |
| :--- | :--- | :--- |
| 강수P | 당일 강수량 (mm) | |
| Dr,i-1 | 전일 말 근권 고갈량 | |
| DP | 심층침투량 | P > Dr,i-1이면 발생 |
| Dr비후 | 강수 후 고갈량 = max(Dr,i-1 − P, 0) | |
| **Ks** | **수분스트레스계수** | **1.0=무스트레스, <1.0=스트레스** |
| ETc_adj | 스트레스 보정 후 실제 증발산량 | Ks × ETc |
| **Dr,i** | **당일 말 근권 고갈량** | **RAW 미만=안전, 초과=관수 필요** |
| **관수 필요** | **● 표시** | **Dr,i ≥ RAW** |
| 필요 순관수량 In | 당일 이론적 관수 필요량 | ● 인 날만 표시 |
| 필요 총관수량 Ig | In / Ea | ● 인 날만 표시 |

**색상 의미**

| 색상 | 조건 | 의미 |
| :--- | :--- | :--- |
| 🔴 빨간 배경 | Dr ≥ RAW | 관수 필요 |
| 흰 배경 | Dr < RAW | 정상 |

연속 ● 구간은 무관수 상태에서 Dr이 누적되는 구간입니다. 관수를 했다면 실제 Dr은 이보다 낮습니다.

### ◆ 시트 1: 지점비교

한 행 = 한 지점.

**ETo 컬럼 (초록 헤더)**

| 컬럼 | 해석 |
| :--- | :--- |
| pan/PM | ETo_pan ÷ ETo_PM. 1.0이면 두 방법 일치. 모든 지점이 비슷한 값(2026년 0.77~0.85)이면 방법 간 계통적 차이이므로, **다른 지점과 동떨어진 지점만** 증발량·일사 자료를 점검 ([THEORY.md 3장](THEORY.md#3-기준증발산량-eto--fao-56-penman-monteith)) |
| 6·7·8월 | 해당 월의 pan/PM 비율 |
| 일사결측 | 클수록 ETo 추정 정확도 낮음 |

**물수지 컬럼 (갈색 헤더)**

| 컬럼 | 해석 |
| :--- | :--- |
| ΣP | 기간 총강수량 |
| ΣPeff | 유효강수량. 낮을수록 집중호우 손실 큼 |
| 유효강수율% | 50% 미만이면 집중호우 패턴 지배적 |
| ΣETo | 기준작물 물 소비량 합계 |
| **물수지 ΣPeff-ΣETo** | **음수(적색)=자연강우 부족, 양수(녹색)=충분** |
| 스트레스 일수 | Ks < 1.0인 날 수 |
| 관수필요 발생일수 | Dr ≥ RAW인 날 수 |

### ◆ 시트 4: 관수필요_달력

지점 간 비교에서 가장 직관적인 시트입니다.

**히트맵 (상단)** — 셀 숫자 = Dr (mm)

| 색상 | Dr 범위 | 의미 |
| :--- | :--- | :--- |
| 흰색 | Dr ≈ 0 | 포장용수량에 가까운 상태 |
| 연녹 | 0 < Dr < RAW×0.5 | 안전 |
| 연노 | RAW×0.5 ≤ Dr < RAW | 주의 (관수 계획 시작) |
| 연주황~연적 | RAW ≤ Dr < TAW×0.6 | 관수 필요 |
| 진적 (굵은 글씨) | Dr ≥ TAW×0.6 | 심각한 스트레스 |
| 회색 | — | 데이터 결측 |

**Dr 선형 차트 (하단)**
- 실선: 각 지점의 Dr 추이
- 빨간 점선: RAW (관수 트리거 라인)
- Dr이 점선을 위로 넘어서는 날 = 관수 필요 시점

## cropwater_fcst.py verify 결과 — 단기예보 H2 검증 (10시트, --compare 시 11시트)

> 02-Cycle 가설검증용입니다. 과거 단기예보로 만든 예보 ETo·ETc를 ASOS 관측값과 비교해, 예보를 관수 판단에 쓸 만한지(H2) 판정합니다. 이론은 [THEORY.md 9장](THEORY.md#9-예보-기반-etoetc--기상청-단기예보)에 있습니다.

**노란 칸**(요약의 합격 기준, 설정, Rs계수)을 바꾸면 다시 계산됩니다. 오차분해·격자비교 시트만 Python 계산값이라 다시 계산되지 않습니다.

### ◆ 시트 1: 요약

| 영역 | 읽는 법 |
| :--- | :--- |
| 자료 정보 | 예보 격자·발표 수·누락, 서비스 발표 수, 대상일, 관측 기준, Rs 계수, Kc |
| H2 합격 기준 | 개선율 기준(30%)과 D+1 RMSE 상한(1.0 mm/일). 노란 칸을 바꾸면 판정이 바뀝니다 |
| 판정 표 | 발표별 D+1~D+3 최소 개선율, D+1 RMSE, 판정(통과=녹색, 미달=적색) |
| 선행시간별 ETo·ETc 표 | n, 관측·예보 평균, MBE, RMSE, R², 지속성·7일평균 RMSE와 개선율. 'H2 판정 대상' ○ = D+1~D+3 |
| 3일 누적 | 발표별 첫 3개 대상일 합(아침 D+0~D+2, 저녁 D+1~D+3). 상대 RMSE = RMSE ÷ 관측 3일합 평균 |
| 주요 발견 | ①~③은 셀과 연결된 수식 문장, ④ 이후는 Python 분석(오차분해)과 자료 조건 경고 |
| 차트 | 선행시간별 RMSE(예보·지속성·7일평균), 관측 ETo와 D+1 예보 시계열 |

- **개선율**: 1 − RMSE_예보 ÷ RMSE_기준선. 50%면 오차가 기준선의 절반입니다.
- **MBE가 음수**면 예보가 관측보다 작습니다(과소추정). 물수지에서는 고갈량(Dr)이 실제보다 천천히 늘어 관수 필요일을 늦게 알립니다.

### ◆ 시트 2: 일별비교

발표 × 대상일 한 행(아침 4일 + 저녁 4일 × 발표 수). 열 묶음은 1행 머리글에 표시됩니다.

| 열 | 내용 |
| :--- | :--- |
| A~F | 발표번호, 구분(아침·저녁), 발표시각, 발표일, 선행일 k, 대상일 |
| G~N | 예보 일 입력: 마지막날 여부(3시간·코드), Tmax, Tmin, ea, u10, 강수, 시각 수, 이전 발표로 채운 시각 수 |
| O~X | 강수유무, Ra, Rso, Rs(S3·S1), u2, PM 중간값 |
| **Y** | **예보 ETo (S3)** — 주 결과 |
| Z | 예보 ETo (S1, kRs 0.16) — 비교용 |
| AA~AC | 관측 ETo, 지속성(발표일 전날 관측), 7일평균(발표일 전 7일) |
| AD~AG | 오차(예보 − 관측) |
| AH~AO | Kc, 예보·관측·기준선 ETc와 오차 |
| AP~BB | 입력 진단: 관측 Tmax·Tmin·ea·u10·Rs·강수유무, 입력별 오차, 강수 판정(적중·놓침·오보·무강수 일치) |

- 자동 필터가 걸려 있습니다. 구분·선행일로 걸러 보면 특정 선행시간의 날짜별 오차를 볼 수 있습니다.
- 'N 이전 발표로 채운 시각 수'가 8이면 00~07시를 전날 저녁 발표로 채운 것입니다(아침 D+0).

### ◆ 시트 3: 3일누적 / 시트 4: 입력진단

- **3일누적**: 발표 한 행. 예보·관측·지속성의 3일 합과 오차.
- **입력진단**: 발표 × 선행일별 입력 편향(예보 − 관측)과 RMSE, 강수유무 적중표(POD·FAR·CSI).
  - 예보 최고·최저기온(TMX 09~18시, TMN 03~09시)과 ASOS 일최고·최저(0~24시)는 정의가 달라 편향의 일부가 정의 차이입니다.
  - 아침 D+k와 전날 저녁 D+(k+1)은 같은 대상일입니다. 최고·최저기온 예보가 17시 이후 발표에서 잘 바뀌지 않아 두 발표의 기온 진단이 거의 같습니다.

### ◆ 시트 5: 오차분해 (Python 계산값)

| :--- | :--- |
| ① 입력 교체 | 예보 입력을 하나씩 관측값으로 바꿨을 때의 RMSE. 가장 많이 줄어드는 입력이 오차의 주원인 |

| ③ 입력 편향 | 전체 기간 평균 편향 = 보정값의 크기 |

### ◆ (선택) 격자비교 — `--compare`로 다른 격자 예보를 함께 넣었을 때

같은 관측·Rs 계수·Kc로 두 격자의 예보를 계산해 비교합니다. 차이는 모두 예보 격자에서 옵니다.

| 표 | 읽는 법 |
| :--- | :--- |
| ① 선행시간별 성능 | 두 격자의 MBE·RMSE·개선율. 'RMSE 차이 A−B'가 음수면 이 검증의 격자(A)가 더 좋음 |
| ② 입력 편향 | 두 격자의 최고·최저기온·풍속 편향(예보 − 관측) |
| ③ 직접 차이 | 같은 발표·선행일끼리 A − B의 평균·표준편차, 강수유무 일치율 |
| ④ 월별 직접 차이 | 격자 차이가 계절에 따라 달라지는지 |

- 예) 춘천: 73_134(ASOS 101 격자) − 73_135(신북읍) 최고기온 +1.1℃, 예보 ETo +0.16 mm/일 (2026년 4~6월)

### ◆ 시트 6: Rs계수 / 시트 7: 관측 / 시트 8: 설정

- **Rs계수**: S3 계수 a·b·c와 지점 kRs(노란 칸), 보정 자료 기간. 아래 표는 H1 재검증(관측 입력 + Rs만 추정) 결과와 월별 편향입니다. 계수를 바꾸면 예보 ETo까지 모두 다시 계산됩니다.
- **관측**: ASOS 일자료(값)와 관측 ETo·Kc·ETc·직전 7일 평균(수식). 관측 ETo는 01-Cycle 계산과정 시트와 같은 값입니다.
- **설정**: 지점 위도·고도·풍속계 높이, 예보 풍속 높이, 예보 기압(식7), 강수유무 기준, Kc 파라미터(01-Cycle 워크북 값).

### ◆ 시트 9: 방법 / 시트 10: 차트자료

- **방법**: 자료, 일 입력 만들기(지나간 시각 채움, 마지막 날 코드 변환), 기준선, 지표, 판정, 한계.
- **차트자료**: 요약 시트 시계열 차트의 원본(대상일별 관측 ETo, 아침·저녁 D+1 예보).

## 공통 주의사항

| 항목 | 내용 |
| :--- | :--- |
| **무관수 가정** | 물수지는 자연강우만 반영. 실제 관수가 있었다면 Dr은 이보다 낮음 |
| **실측값 기반** | ASOS 실측 일별 데이터 사용. 기후 평년값과 다를 수 있음 |
