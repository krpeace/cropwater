# 엑셀 결과 해석 가이드

> CropWater가 생성하는 Excel 파일의 시트별 읽는 법과 주의사항을 다룹니다.

## cropwater_station.py 결과 (6시트)

### ◆ 시트 1: 설정

프로그램이 사용한 모든 파라미터가 표시됩니다. **노란 셀**은 직접 편집 가능하며, 값을 바꾸면 계산과정·결과요약·물수지 시트가 자동 재계산됩니다.

| 섹션 | 주요 항목 | 편집 |
| :--- | :--- | :---: |
| [1] 지점 정보 | 위도·고도·풍속계높이 | △ |
| [2] 증발접시 | 풍상거리(fetch) | ○ |
| [3] 작물 선택 | 작물명·시나리오 | × |
| [4] Kc 파라미터 | Kc_ini/mid/end (현지기상 보정 후 표시) | △ |
| [5] 생육단계 | 발아일·L_ini/dev/mid/late | ○ |
| [6] 멀칭 | 멀칭 보정계수 | ○ |
| [7] 생육기간 | 중기·후기 시작/종료일 (자동 계산) | × |
| **[8] 토양·근권** | **θFC·θWP·Zr·p·TAW·RAW·Dr₀·Ea** | **○** |

> TAW·RAW는 [8] 섹션에서 자동 계산됩니다. θFC·θWP·Zr 변경 시 즉시 반영됩니다.

---

### ◆ 시트 2: 원데이터

기상청 ASOS 일별 원자료 그대로입니다. 이 시트는 수정하지 마세요.

| 결측 항목 | 처리 |
| :--- | :--- |
| `sumGsr` (일사량) | 일조시간(`sumSsHr`)으로 Ångström 공식 추정 |
| `avgWs` (풍속) | 해당 일 ETo 계산 불가, 결측 처리 |

---

### ◆ 시트 3: 계산과정

모든 셀이 라이브 수식입니다. 설정 시트 변경 시 자동 재계산되며, 셀 클릭 시 FAO-56 수식을 직접 확인할 수 있습니다.

| 열 | 내용 |
| :---: | :--- |
| A | 일자 |
| U | ETo_PM (mm/day) — FAO-56 Penman-Monteith |
| V | 생육단계 (초기·발육기·중기·후기·휴면) |
| W | 일별 Kc (생육단계 선형보간 + 현지기상 보정) |
| Z | ETo_pan (mm/day) — 증발접시법 |
| AA | ETc_PM = Kc × ETo_PM |

### ◆ 시트 4: 결과요약

**ETo·ETc 요약**

| 항목 | 읽는 법 |
| :--- | :--- |
| ETo_PM 기간합계 | 분석 기간 기상 에너지 합산. 연간 600~900mm가 일반적 |
| ETc_PM 기간합계 | 분석 기간 작물 물 소비량 합산 |

**물수지 요약** — 무관수(자연강우만) 가정

| 항목 | 해석 |
| :--- | :--- |
| 기간 총강수 ΣP | ASOS 관측 강수량 합계 |
| 유효강수 | 근권이 흡수한 강수량 = ΣP − ΣDP |
| 심층침투 ΣDP | 근권 아래로 손실된 양 |
| 유효강수율 (%) | 낮을수록 집중호우 손실이 큰 것 |
| 관수 필요 발생 일수 | Dr ≥ RAW인 날 수 |
| 필요 순관수량 ΣIn | 스트레스 발생일 기준 이론적 보충 필요량 |
| 필요 총관수량 ΣIg | ΣIn / Ea (손실 포함 실제 공급량) |

> ⚠️ 필요 순관수량·총관수량은 **이론적 필요량**이며 실측 관수량이 아닙니다. 무관수 가정하의 누적 부족량입니다.

---

### ◆ 시트 5: 물수지

일별 관수 필요 시점을 확인하는 핵심 시트입니다.

| 열 | 내용 | 판단 기준 |
| :--- | :--- | :--- |
| 강수P | 당일 강수량 (mm) | |
| Dr,i-1 | 전일 말 근권 고갈량 | |
| DP | 심층침투량 | P > Dr,i-1이면 발생 |
| Dr비후 | 강수 후 고갈량 = max(Dr,i-1 − P, 0) | |
| **Ks** | **수분스트레스계수** | **1.0=무스트레스, <1.0=스트레스** |
| ETc_adj | 스트레스 보정 후 실제 증발산량 | Ks × ETc |
| **Dr,i** | **당일 말 근권 고갈량** | **RAW 미만=안전, 초과=관수 필요** |
| **관수 필요** | **● 표시** | **Dr,i ≥ RAW** |
| 필요 순관수량 In | 당일 이론적 관수 필요량 | ● 인 날만 표시 |
| 필요 총관수량 Ig | In / Ea | ● 인 날만 표시 |

**색상 의미**

| 색상 | 조건 | 의미 |
| :--- | :--- | :--- |
| 🔴 빨간 배경 | Dr ≥ RAW | 관수 필요 |
| 흰 배경 | Dr < RAW | 정상 |

연속 ● 구간은 무관수 상태에서 Dr이 누적되는 구간입니다. 관수를 했다면 실제 Dr은 이보다 낮습니다.

## cropwater_multi.py 결과 (5시트)

### ◆ 시트 1: 지점비교

한 행 = 한 지점.

**ETo 컬럼 (초록 헤더)**

| 컬럼 | 해석 |
| :--- | :--- |
| pan/PM | 0.7~0.8이 정상 범위. 벗어나면 일사·증발량 데이터 품질 재확인 |
| 6·7·8월 | 해당 월의 pan/PM 비율 |
| 일사결측 | 클수록 ETo 추정 정확도 낮음 |

**물수지 컬럼 (갈색 헤더)**

| 컬럼 | 해석 |
| :--- | :--- |
| ΣP | 기간 총강수량 |
| ΣPeff | 유효강수량. 낮을수록 집중호우 손실 큼 |
| 유효강수율% | 50% 미만이면 집중호우 패턴 지배적 |
| ΣETo | 기준작물 물 소비량 합계 |
| **물수지 ΣPeff-ΣETo** | **음수(적색)=자연강우 부족, 양수(녹색)=충분** |
| 스트레스 일수 | Ks < 1.0인 날 수 |
| 관수필요 발생일수 | Dr ≥ RAW인 날 수 |

---

### ◆ 시트 2: 일별_전지점

전 지점 일별 데이터를 한 시트에서 비교합니다. 특정 날짜에 어느 지점이 더 건조했는지 확인할 때 활용합니다.

| 색상 | 조건 |
| :--- | :--- |
| 🔴 빨간 배경 (Dr 열) | Dr ≥ RAW — 관수 필요 |
| 🟡 노란 배경 (Ks 열) | Ks < 1.0 — 스트레스 발생 |

---

### ◆ 시트 3: 월별_물수지

지점 × 월 교차 집계입니다.

| 판단 기준 | 의미 |
| :--- | :--- |
| 월별 물수지 음수(적색) | 자연강우 부족 달 |
| 관수필요 발생일수 많음 | 집중 관리 필요 시기 |
| 유효강수율 낮음 | 집중호우가 있었으나 흡수는 적었던 달 |

---

### ◆ 시트 4: 관수필요_달력

지점 간 비교에서 가장 직관적인 시트입니다.

**히트맵 (상단)** — 셀 숫자 = Dr (mm)

| 색상 | Dr 범위 | 의미 |
| :--- | :--- | :--- |
| 흰색 | Dr ≈ 0 | 포장용수량에 가까운 상태 |
| 연녹 | 0 < Dr < RAW×0.5 | 안전 |
| 연노 | RAW×0.5 ≤ Dr < RAW | 주의 (관수 계획 시작) |
| 연주황~연적 | RAW ≤ Dr < TAW×0.6 | 관수 필요 |
| 진적 (굵은 글씨) | Dr ≥ TAW×0.6 | 심각한 스트레스 |
| 회색 | — | 데이터 결측 |

**Dr 선형 차트 (하단)**
- 실선: 각 지점의 Dr 추이
- 빨간 점선: RAW (관수 트리거 라인)
- Dr이 점선을 위로 넘어서는 날 = 관수 필요 시점

## 공통 주의사항

| 항목 | 내용 |
| :--- | :--- |
| **무관수 가정** | 물수지는 자연강우만 반영. 실제 관수가 있었다면 Dr은 이보다 낮음 |
| **실측값 기반** | ASOS 실측 일별 데이터 사용. 기후 평년값과 다를 수 있음 |
| **기준작물 차이** | `cropwater_station`: 작물별 Kc 적용 ETc / `cropwater_multi`: Kc=1 기준 ETo (지점 간 기상 비교 목적) |
| **파라미터 조정** | 설정 시트에서 θFC·θWP·Zr·p를 바꾸면 물수지 시트 전체 자동 재계산 |
