| 구분 | 점검 항목 |
| :---: | :--- |
| 논리 L1 | 이번 단계에서 쓰는 식·가정이 THEORY.md에 근거(식 번호·출처)가 있는가. 없으면 **THEORY.md를 먼저 갱신** |
| 논리 L2 | 코드 ↔ THEORY.md ↔ ARCHITECTURE.md ↔ RESULTS_GUIDE.md 사이에 식·단위·결측처리·해석 불일치가 없는가 |
| 논리 L3 | 검증 설계가 해당 가설을 실제로 검정하는가. **무엇을 검정하지 못하는지**도 적는다 |
| 실증 E1 | 기준값 재현: 기존 산출물(01-Cycle 등)과 일치하는가 |

| 실증 E3 | 자료 품질·대표성: 기간, 지점, 결측, 물리적 범위(예: Rs ≤ Rso) |
| 실증 E4 | 기준선(지속성 등)보다 나은가 |

**판정**
- 통과

- 보류: 원인과 재시도 계획을 명시

#### 논리 점검

- **L1 — 근거**

- **L2 — 문서·코드 불일치 (발견 5건)**
  1. THEORY 3장 예시의 u2 = 0.57 m/s → **수정함**
     - 식(47), 코드, 단위테스트는 모두 0.748입니다.
     - ETo 1.77은 ea = avgPv(1.03 kPa)일 때의 값이고, 평균습도로 ea를 계산하면 1.62입니다. 예시에 ea 기준을 명시했습니다.
  2. pan/PM "0.7~0.8 = 수렴·정상" 해석 (THEORY 3장, ARCHITECTURE 8장, RESULTS_GUIDE) → **수정함**
     - 두 ETo 추정치가 일치하면 비율은 1.0이어야 합니다.
     - 2026년 9개 지점은 모두 0.77~0.85로 일정하므로 계통적 차이입니다. 프로그램 `설명` 시트의 판정("계통적 편차")과도 같습니다.
     - 춘천 역산 계수(ΣETo_PM ÷ ΣEpan)는 0.97(6~8월 1.11)로, FAO-56 Class A 상한 0.85를 넘습니다.
  3. THEORY 4장 Kc 기후보정 조건 문구: Kc_end 조건이 Kc_mid 식 아래에 있었음 → **수정함**
  4. **식(88) 심층침투** → **3단계 전 결정 필요**
     - FAO-56 원식: DP = (P − RO) + I − ETc − Dr,i−1 ≥ 0
     - 문서와 코드는 −ETc 항을 생략하고 있어, 비 온 날 Dr이 0이 아니라 ETc 값으로 끝납니다.
     - 예보 물수지(3단계)에 그대로 들어가는 부분입니다.
  5. **THEORY 5·6장 물수지 예시의 계산 불일치** → **3단계 전 수정 필요**
     - 5/17: Ks를 0.88로 표시했지만 Dr 갱신은 Ks = 1로 계산했습니다.
     - 5/20: Ks를 0.00으로 표시했고 ETc 2.7이 반영되지 않았습니다.
     - '실제' 예시라고 되어 있지만, 5월 초 ETc 4.2~5.1은 4장 사과 Kc(5월 초 ≈ 0.6)와 맞지 않습니다. 2026 실측으로 다시 만들 것을 권장합니다.
