| 구분 | 점검 항목 |
| :---: | :--- |
| 논리 L1 | 이번 단계에서 쓰는 식·가정이 THEORY.md에 근거(식 번호·출처)가 있는가. 없으면 **THEORY.md를 먼저 갱신** |

  1. THEORY 3장 예시의 u2 = 0.57 m/s → **수정함**

  2. pan/PM "0.7~0.8 = 수렴·정상" 해석 (THEORY 3장, ARCHITECTURE 8장, RESULTS_GUIDE) → **해석을 수정함** (지표 전환은 후속 #7)

  3. THEORY 4장 Kc 기후보정 조건 문구 → **수정함**
  4. **식(88) 심층침투** → **G3 전 결정 필요** (게이트 재배치 후 G4 전)

     - 5/20: Ks를 0.00으로 표시했고 ETc 2.7이 반영되지 않았습니다.
     - 5월 초 ETc가 4장 사과 Kc와 맞지 않습니다.
- **L3 — 설계**
  - perfect-prognosis는 구조오차(H1)만 검정하고, 예보오차·대표성 오차(H2)는 검정하지 않습니다. 9장에 명시했습니다.
