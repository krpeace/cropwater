## 게이트 운영 방법

각 단계가 끝나면 아래 항목을 점검합니다. 판정과 근거를 이 문서에 남긴 뒤 다음 단계로 넘어갑니다. 같은 단계에서 코드와 docs를 함께 갱신합니다.

| 구분 | 점검 항목 |
| :---: | :--- |
| 논리 L1 | 이번 단계에서 쓰는 식·가정이 THEORY.md에 근거(식 번호·출처)가 있는가. 없으면 **THEORY.md를 먼저 갱신** |
| 논리 L2 | 코드 ↔ THEORY.md ↔ ARCHITECTURE.md ↔ RESULTS_GUIDE.md 사이에 식·단위·결측처리·해석 불일치가 없는가 |
| 논리 L3 | 검증 설계가 해당 가설을 실제로 검정하는가. **무엇을 검정하지 못하는지**도 적는다 |

- 통과

  1. THEORY 3장 예시의 u2 = 0.57 m/s → **수정함**
     - 식(47), 코드, 단위테스트는 모두 0.748입니다.

  2. pan/PM "0.7~0.8 = 수렴·정상" 해석 (THEORY 3장, ARCHITECTURE 8장, RESULTS_GUIDE) → **해석을 수정함** (지표 전환은 후속 #7)

     - 춘천 역산 계수는 0.97(6~8월 1.11)로, FAO-56 Class A 상한 0.85를 넘습니다.
  3. THEORY 4장 Kc 기후보정 조건 문구 → **수정함**
  4. **식(88) 심층침투** → **G3 전 결정 필요** (게이트 재배치 후 G4 전)

  5. **THEORY 5·6장 물수지 예시의 계산 불일치** → **G3 전 수정 필요** (게이트 재배치 후 G4 전)

     - 5/20: Ks를 0.00으로 표시했고 ETc 2.7이 반영되지 않았습니다.
     - 5월 초 ETc가 4장 사과 Kc와 맞지 않습니다.
- **L3 — 설계**
  - perfect-prognosis는 구조오차(H1)만 검정하고, 예보오차·대표성 오차(H2)는 검정하지 않습니다. 9장에 명시했습니다.

  - 예보 최저·최고기온(아침최저 03:01~09:00, 낮최고 09:01~18:00)과 ASOS 일 최저·최고(0~24시)는 정의가 다릅니다. 이 차이도 9장에 추가했습니다.
