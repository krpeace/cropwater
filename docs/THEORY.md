## 1. 왜 관수가 필요한가

토양수분이 부족해지면 식물에 **수분스트레스(water stress)**가 발생합니다.

| 스트레스 반응 | 결과 |
| :--- | :--- |
| 기공 닫힘 → 광합성 감소 | 생육 둔화 |
| 세포 팽압 저하 | 잎 시들음 |
| 과실 비대기 스트레스 | 수량 감소·품질 저하 (사과: 소과화, 배추: 구 형성 불량) |

관수의 목적은 **토양수분을 작물이 스트레스를 받지 않는 범위(Dr < RAW)로 유지**하는 것입니다.

## 2. 증발산

**증발산(ET, Evapotranspiration)** = 증발(E) + 증산(T)

```
증발 (Evaporation)  : 토양·수면에서의 직접 기화. 일사·바람·습도에 의해 결정
증산 (Transpiration): 식물이 뿌리로 흡수한 물을 기공으로 내보내는 현상.
                      기상 조건 + 작물 종류 + 생육단계에 의해 결정

단위: mm/day  (1mm = 1m²당 1L = 1ha당 10톤/day)
```

## 3. 기준증발산량 ETo — FAO-56 Penman-Monteith

작물마다 물 소비량을 직접 측정하는 대신, FAO-56은 **기준작물(잔디)** 기준의 ETo를 먼저 계산하고 작물별 보정계수(Kc)를 곱합니다.

### ◆ Penman-Monteith 방정식 [식(6)] — FAO-56 표준

```
        0.408 × Δ × (Rn - G) + γ × (900/(T+273)) × u2 × (es - ea)
ETo = ─────────────────────────────────────────────────────────────
                    Δ + γ × (1 + 0.34 × u2)
```

| 기호 | 이름 | 단위 | 의미 |
| :--- | :--- | :--- | :--- |
| Rn | 순복사량 | MJ/m²/day | 작물이 받는 실질 에너지 (증발 에너지 원) |
| G | 지중열유속 | MJ/m²/day | 땅속으로 전달되는 열 (일 단위 ≈ 0) |
| T | 일평균기온 | °C | 높을수록 포화증기압 증가 |
| u2 | 2m 풍속 | m/s | 수증기를 날려 증발 촉진 |
| es − ea | 증기압 결핍 | kPa | 공기의 건조도 (클수록 증발 왕성) |
| Δ | 포화증기압 곡선 기울기 | kPa/°C | 기온 변화에 따른 포화증기압 변화율 |
| γ | 건습계 상수 | kPa/°C | 기압에 의존 (고지대일수록 작음) |

**분자 두 항의 의미:**
- `Δ × (Rn - G)` → 복사 에너지에 의한 증발
- `γ × u2 × (es - ea)` → 건조·바람에 의한 대류 증발

### ◆ 기상청 ASOS 데이터 대응

| FAO-56 변수 | ASOS 필드 | 결측 시 처리 |
| :--- | :--- | :--- |
| Tmax, Tmin | `maxTa`, `minTa` | 필수. 필수 입력이 빈 날·날짜가 빠진 날은 '결측'으로 표시하고 물수지의 ETo는 앞 7일 평균, 강수는 없으면 0 (01-Cycle, #20). 02-Cycle 예보 물수지는 그날 아침 발표 D+0 예보로 채움 |
| u10 → u2 | `avgWs` | 식(47): u2 = u10 × 4.87/ln(67.8×10−5.42) |
| Rs (일사량) | `sumGsr` | 일조시간(`sumSsHr`)으로 Ångström 공식 추정 |
| ea (실제증기압) | `avgPv` × 0.1 kPa | 이슬점(`avgTd`) 또는 상대습도(`avgRhm`) 대체 |
| P (기압) | `avgPa` × 0.1 kPa | 해발고도로 추정: P = 101.3 × ((293−0.0065z)/293)^5.26 |

### ◆ 실제 계산 예시

```
춘천(ASOS 101), 2026-04-01
  Tmax=17.7°C, Tmin=5.2°C
  ea=1.03 kPa (avgPv 10.3 hPa, 참고: 평균습도 83.9%)
  u10=1.0 m/s → u2=0.75 m/s [식47], Rs=10.47 MJ/m²/day, P=100.35 kPa (avgPa)

  → ETo = 1.77 mm/day
  → 잔디밭 1m²당 1.77L/day 증발산
```

> ea를 평균습도로 계산하면(83.9% × es) 같은 날 ETo는 1.62 mm/day입니다. 위 표의 ea 우선순위(증기압 → 이슬점 → 상대습도)가 결과에 영향을 줍니다.

### ◇ 증발접시 방법 — 대안적 ETo 추정

ASOS에서는 대형증발접시 일증발량(`sumLrgEv`, mm/day)을 제공합니다. 증발접시 관측값(Epan)에 기후·위치 보정계수 Kp를 곱해 ETo를 추정합니다.

```
ETo_pan = Kp × Epan
```

**Kp 결정 인자 (FAO-56 Table 30, Allen-Pruitt 방법)**

| 인자 | 영향 |
| :--- | :--- |
| u2 (풍속) | 클수록 Kp 감소 (접시는 실제 작물보다 바람 영향 과다) |
| RH (습도) | 높을수록 Kp 증가 |
| 풍상거리(fetch) | 접시 주변 노출 상태 (기본값 100m) |

**PM 방법과의 비교**

| | ETo_PM | ETo_pan |
| :--- | :--- | :--- |
| 필요 데이터 | 기온·습도·풍속·일사량·기압 | 대형증발량(Epan)·풍속·습도 |
| 일사 결측 시 | 일조시간으로 Ångström 보정, 일조도 없으면 식(50) ([9장](#9-예보-기반-etoetc--기상청-단기예보)) | 영향 없음 |
| 정확도 | 국제 표준 (기준값) | PM 대비 ±10~20% 편차 가능 |
| CropWater 활용 | 주 계산값 | 크로스체크·검증용 |

> **실용 포인트:** cropwater_multi.py `지점비교` 시트의 pan/PM은 ETo_pan ÷ ETo_PM이므로, 두 방법이 같은 값을 내면 **1.0**입니다.
> 2026년(1/1~9/13) 9개 지점은 모두 0.77~0.85로 비슷하게 낮았습니다. 이것은 개별 지점의 자료 오류라기보다 **두 방법 사이의 계통적 차이**(Class A 계수 Kp 가정과 ASOS 증발계 설치환경의 차이)를 뜻합니다.
> 실제로 춘천의 역산 계수(ΣETo_PM ÷ ΣEpan)는 0.97(6~8월 1.11)로, FAO-56 Class A 표(Table 5)의 상한 0.85를 넘습니다.
>
> 이 비율은 다음처럼 씁니다.
> - 다른 지점들과 동떨어진 값을 보이는 지점을 찾는 **상대 비교**에 씁니다.
> - 일사 자료의 절대 품질은 **Rs ≤ Rso 검사**(FAO-56 권고)로 확인합니다. 2026년 춘천 ASOS는 256일 중 1일만 Rs/Rso가 1.0을 넘었습니다(최대 1.01).
>
> FAO-56도 증발접시는 PM ETo에 맞춰 보정해 쓰고, 10일 이상 기간에 적용하라고 권합니다.

## 4. 작물계수 Kc와 작물증발산량 ETc

```
ETc = Kc × ETo
```

- `Kc = 1.0`: 잔디와 동일한 물 소비
- `Kc > 1.0`: 잔디보다 많이 소비 (사과 중기: Kc ≈ 1.2)
- `Kc < 1.0`: 잔디보다 적게 소비 (발아 초기·수확기)

### ◆ 생육단계별 Kc 변화

```
Kc
 │
1.2 ─────────────────────── Kc_mid (중기)
 │                       ╱─────────╲
 │                     ╱             ╲─── Kc_end (후기)
0.7 ─── Kc_ini ───╱
(초기)   (발육기)   (중기)          (후기)
  L_ini    L_dev    L_mid            L_late
```

사과 (FAO-56 Table 12, 초생재배·동해 지역):

| 생육단계 | 기간 (일) | Kc | 시기 |
| :--- | :---: | :---: | :--- |
| 초기 (ini) | 20 | 0.50 | 발아~착엽 초기 |
| 발육기 (dev) | 70 | 0.50 → 1.20 | 잎 전개·생장 왕성 |
| 중기 (mid) | 90 | 1.20 | 과실 비대기 |
| 후기 (late) | 30 | 1.20 → 0.95 | 성숙·수확기 |

> 봄철(4~5월)은 Kc가 낮지만 ETo가 빠르게 올라가는 시기입니다. `ETc = 낮은 Kc × 높아지는 ETo` 구조여서 실제 물 수요는 무시할 수 없습니다.

### ◇ 현지기상 보정 [식(62)·(65)] — 선택적 보정

```
Kc_mid_adj = Kc_mid_tab + [0.04×(u2−2) − 0.004×(RHmin−45)] × (h/3)^0.3
```

- `u2`: 생육 중기 평균 2m 풍속
- `RHmin`: 생육 중기 평균 최저상대습도 (%)
- `h`: 작물 키 (m)
- 적용 범위: u2 1~6 m/s, RHmin 20~80%로 제한 (코드 `kc_climate_adjust`와 동일)
- **Kc_mid는 식(62)로 항상 보정하고, Kc_end는 같은 형태의 식(65)로 보정하되 표값 Kc_end > 0.45인 경우에만 적용**

## 5. 토양수분과 물 저장

토양의 물 저장을 **양동이**로 이해하면 직관적입니다.

```
지표면
 ─────────────────────────────────── ← 물이 넘치면 지표유출(RO)
 │                                 │
 │  ── 포장용수량(FC) ──           │ ← 중력배수 완료 후 수분 상한
 │                                 │
 │  ← 이 범위가 TAW (총유효수분) → │
 │                                 │
 │  ── 영구위조점(WP) ──           │ ← 이 아래는 뿌리 흡수 불가
 │                                 │
 ─────────────────────────────────── ← 근권 하단 (심층침투DP 경계)
```

### ◆ 주요 파라미터

**포장용수량 FC (Field Capacity)**
중력배수가 완료된 상태의 토양수분 함량. 작물 이용 가능 수분의 상한선.

**영구위조점 WP (Wilting Point)**
작물이 더 이상 물을 흡수할 수 없어 영구적으로 시드는 수분 함량.

**총유효수분 TAW [식(82)]**
```
TAW = 1000 × (FC − WP) × Zr   (mm)

예시: 양토, 사과(Zr=1.0m)
  TAW = 1000 × (0.22 − 0.10) × 1.0 = 120mm
  → ETc 5mm/day 기준 24일치 저장량
```

**쉽게이용가능수분 RAW [식(83)]**
```
RAW = p × TAW   (mm)

p = 고갈계수 (FAO-56 Table 22): 사과 0.50, 배추 0.45

예시: 사과, 양토
  RAW = 0.50 × 120 = 60mm
  → Dr이 60mm를 초과하면 수분스트레스 시작
```

### ◆ RAW·Dr 관계 도해

**① 토양 수분 상태 단면도**

```
 FC ────────────────────────────── 0mm ← Dr 기준점(포장용수량 = 고갈 없음)
 │                                 │
 │   ← RAW = 60mm →               │ Dr < RAW: 작물 무스트레스, 관수 불필요
 │                                 │
 RAW ─────────────────────────── 60mm ← Dr = RAW: 관수 트리거 지점 (●)
 │                                 │
 │   ← TAW − RAW = 60mm →         │ Dr > RAW: Ks < 1, 수분스트레스 진행
 │                                 │
 WP ─────────────────────────── 120mm ← Dr = TAW: 완전 고갈 (고사 위험)
```

> Dr(Root zone **D**epletion)은 **포장용수량(FC)에서 현재 수분이 얼마나 빠졌는가**를 나타냅니다.  
> Dr = 0이면 토양이 꽉 찬 상태, Dr = TAW이면 완전 고갈 상태입니다.

**② 일별 Dr 변화 흐름**

```
전일 Dr(i-1)
      │
      ├─ 강수 P, 관수 I → Dr 감소 (토양에 물이 채워짐. 관수는 공급량 × 관수효율 Ea만 들어감)
      │
      ├─ ETc_adj만큼 → Dr 증가 (작물이 물을 소비)
      │     └─ 전날 끝 Dr(i-1)이 RAW를 넘으면 Ks < 1, ETc_adj = Ks × ETc (소비 둔화)
      │
      ├─ P + I > Dr(i-1) + ETc_adj → 남는 물은 심층침투(DP)로 손실, Dr(i) = 0   [식88]
      │  P + I ≤ Dr(i-1) + ETc_adj → DP = 0, Dr(i) = Dr(i-1) − P − I + ETc_adj
      │
      └─ 당일 Dr(i) 확정 (0 ≤ Dr ≤ TAW)
             │
             ├─ Dr < RAW  → 안전 (관수 불필요)
             └─ Dr ≥ RAW  → 관수 필요 ●
```

**③ 2026년 5월 실제 Dr 추이 (ASOS 101 춘천·사과, 양토 TAW=120, RAW=60, 무관수)**

01-Cycle 워크북(`cropwater_station.py`)의 물수지 시트 값입니다(식88 FAO-56 원식 2026-09-29, Ks 판단 시점 FAO-56 원식 2026-09-30 반영).

## 6. 일별 근권 물수지

### ◆ 물수지 방정식 [식(85)]

```
Dr(i) = Dr(i−1) − (P − RO)(i) − I(i) − CR(i) + ETc_adj(i) + DP(i)    (0 ≤ Dr ≤ TAW) [식85·86]

이 프로그램: 지표유출 RO = 0, 모관상승 CR = 0,
            관수 I = 기록한 관수량(공급량) × 관수효율 Ea (기록이 없으면 0 = 무관수)
   → Dr(i) = Dr(i−1) − P(i) − I(i) + ETc_adj(i) + DP(i)

Dr(i)   : i일 말 근권 고갈량 (mm)
P(i)    : i일 강수량 (mm)
I(i)    : i일 순관수량 (mm). 1 mm = 10a(1,000 m²)당 1톤
ETc_adj : 수분스트레스 보정 후 실제 증발산량
DP(i)   : 심층침투량 (mm)
```

- **관수 기록 (2026-09-30 추가):** 01-Cycle 워크북의 물수지 시트 I열(노란 칸)에 준 관수량(공급량, mm)을 적거나, 실행할 때 `--irrig 관수기록.csv`(날짜, 관수량_mm)로 채웁니다. 근권에는 공급량 × Ea(점적 0.95)가 들어갑니다.
  - 관수를 적으면 Dr이 줄어 다음 ● 시점이 실제 농가 상황에 맞게 늦춰집니다. 비어 있으면 지금까지처럼 무관수(자연강우만)입니다.
  - 예보 물수지(9장)의 출발점인 '어제 끝 Dr'도 이 관수 기록을 반영합니다.

### ◆ 수분스트레스계수 Ks [식(84)]

Dr이 RAW를 초과하면 작물의 실제 증발산이 감소합니다.

```
Dr ≤ RAW :  Ks = 1.0
Dr > RAW :  Ks = (TAW − Dr) / (TAW − RAW)

ETc_adj = Ks × ETc
```

- **판단 시점 — 전날 끝 고갈량 Dr(i−1) (FAO-56 원식, 2026-09-30 결정 #15):** 그날의 비·관수와 증발산은 하루 동안 함께 일어나므로, FAO-56처럼 그날이 시작될 때의 고갈량으로 Ks를 정합니다.
  - 이전에는 그날 비가 먼저 들어간 뒤의 고갈량 max(Dr(i−1) − P(i), 0)을 썼습니다. 차이는 Dr(i−1)이 RAW를 넘은 상태에서 비가 온 날에만 납니다(비 온 날 Ks가 더 작아져 그날 소비가 줄어듦).
  - 2026년 춘천·사과(4/1~9/28): 관수 필요일 43 → 41일(8/19·8/29가 빠짐), ΣDP 235.5 → 238.0 mm, 첫 관수 필요일(5/17)은 같음. 2025년(4/1~9/30)은 22일로 같음.
  - 예보 물수지(9장)도 같은 규칙입니다. 예보 강수는 하루 안의 시각을 가려 쓰지 않으므로, 비가 먼저 온다고 가정하지 않는 원식이 예보와도 맞습니다.

예시 (TAW=120, RAW=60):

| Dr (mm) | Ks | 의미 |
| :---: | :---: | :--- |
| 30 | 1.00 | 무스트레스 |
| 60 | 1.00 | 경계 |
| 90 | 0.50 | 증발산 50%로 감소 |
| 120 | 0.00 | 완전 고갈 (고사 위험) |

### ◆ 심층침투 DP [식(88)] — FAO-56 원식 (2026-09-29 반영)

```
DP(i) = (P − RO)(i) + I(i) − ETc(i) − Dr(i−1) ≥ 0        [FAO-56 식88]

이 프로그램 (RO = 0, I = 관수량 × Ea, ETc는 스트레스 보정 후 값):
DP(i) = max(P(i) + I(i) − ETc_adj(i) − Dr(i−1), 0)
```

그날 증발산으로 쓰고, 근권을 포장용수량까지 채우고도 남는 물(비·관수)만 근권 아래로 빠집니다.

Dr=20mm 상태에서 50mm 비가 오고 그날 ETc_adj가 5mm이면:
- DP = 50 − 5 − 20 = **25mm 손실**
- 근권 기여분 = **25mm** (고갈량 20mm + 그날 소비 5mm)
- 그날 끝 Dr = 0 (포장용수량)

> 2026-09-29 이전 코드는 간이식 DP = max(P − Dr(i−1), 0)을 썼습니다. 당일 ETc를 빼지 않아 DP를 ETc만큼 크게 잡고, 큰 비가 온 날 끝 고갈량을 0이 아니라 ETc로 남겼습니다. 2026년 춘천·사과(4/1~9/28)에서는 ΣDP가 238.4 → 235.5mm, Dr이 날마다 0.3~4.0mm(평균 1.0mm) 작아졌고, 관수 필요일(43일)은 같았습니다.

양토 TAW=120mm, RAW=60mm, 무관수. 01-Cycle 워크북 물수지 시트 값(Ks 판단 시점 원식 반영, LibreOffice 재계산, 파이썬 계산과 10⁻¹³ 이내 일치).

## 7. 유효강수량 — 비가 와도 다 못 쓰는 이유

강수량 전체가 작물에 기여하지 않습니다. 손실 경로는 세 가지입니다.

| 손실 경로 | 발생 조건 |
| :--- | :--- |
| 지표유출 (RO) | 강우강도 > 토양 침투속도 |
| 심층침투 (DP) | 강수량 > 현재 고갈량 Dr + 그날 ETc |
| 차단손실 | 잎·줄기 표면에 맺혀 증발 |

**일별 유효강수 Peff = P − DP = min(P, Dr(i−1) + ETc_adj)**   (지표유출 RO = 0, 관수가 없는 날)

관수가 있는 날은 DP가 비와 관수 중 어느 쪽에서 왔는지 나눌 수 없어, 01-Cycle 결과요약은 관수를 입력하면 유효강수(율)를 '—'로 표시합니다.

Dr=20mm 상태에서 100mm 비, 그날 ETc 5mm → 근권 흡수 25mm(고갈량 20 + 그날 소비 5), 나머지 75mm 심층침투 손실.

**한국 여름 집중호우의 함정:**

```
7월 월강수량 350mm
  USDA SCS 월별 추정: Peff ≈ 160mm (유효율 46%)
  실제 (장마 집중호우 2회에 거의 다 내린 경우, TAW=60mm):
    1회당 흡수 가능 최대량 ≈ 고갈량 60mm + 그날 ETc 약 4mm → 실제 유효강수 ≈ 128mm (유효율 37%)
```

월별 집계는 집중호우 손실을 구조적으로 과소평가합니다. 이것이 이 프로그램이 **일별 Dr 추적**을 사용하는 이유입니다.

## 9. 예보 기반 ETo·ETc — 기상청 단기예보

> 02-Cycle(2026-09~)의 가설검증 기준이 되는 절입니다. 단계별 게이트 점검 기록은 [VALIDATION.md](VALIDATION.md)에 남깁니다.
> 가설검증 범위: **ASOS 101 춘천 · 사과** (2026-09-29 결정)

### ◆ 왜 예보 ETo인가

6장의 관측 기반 물수지는 **어제까지의** Dr을 알려 줍니다. 여기에 예보 ETc를 더하면 **며칠 뒤 Dr ≥ RAW가 되는지**, 즉 관수 필요 예상일을 미리 알 수 있습니다.

```
어제 끝 Dr(관측 물수지, 관수 기록 반영)
  → 대상일마다 Dr = MIN(MAX(Dr(전날) − 예보 강수 + Ks(Dr(전날)) × 예보 ETc, 0), TAW)    [식84·85·88]
  → 처음 Dr ≥ RAW가 되는 날 = 관수 필요 예상일 (관수하지 않는다고 볼 때)
```

예보 강수를 어떻게 넣는지, 예상일의 범위, 두 해 검증 결과는 아래 ◆ 예보 물수지(G4)에 있습니다.

| 갱신 | 사용 발표 | 대상 기간 |
| :--- | :--- | :--- |
| 아침 | 02시 발표 | 오늘 ~ D+3 |
| 저녁 | 17시 발표 | 내일 ~ D+4 |

출력은 엑셀 보고서입니다. 02-Cycle에서는 가설검증용 엑셀을 중심으로 합니다.

### ◆ 일사량 추정 — FAO-56 식(50)

예보에는 일조시간이 없어서 3장의 Ångström 공식을 쓸 수 없습니다. FAO-56은 이때 **기온교차로 일사를 추정하는** Hargreaves 복사식을 제시합니다.

```
Rs = kRs × √(Tmax − Tmin) × Ra        [식50]

kRs = 0.16 (내륙), 0.19 (해안)
원리: 맑은 날은 낮에 많이 데워지고 밤에 많이 식어 일교차가 크다
      → 일교차가 일사량의 대리변수가 된다
추정값은 0.05·Ra ~ Rso 범위로 제한
```

**강수유무 보정 (현장 보정식, FAO-56 외)** — 비 오는 날은 일교차에 비해 일사가 더 적다는 점을 반영합니다.

```
Rs / Ra = a + b × √(Tmax − Tmin) + c × (강수유무: 일강수 ≥ 1 mm이면 1, 아니면 0)

a, b, c : ASOS 관측 Rs로 결정
          예) 춘천 ASOS 2026 (G0 사전검증): a = −0.099, b = 0.186, c = −0.102
          H2 검증 계수 = 2025년 4~9월 180일로 결정 (G2, rs_coef.csv)
                        a = −0.0971, b = 0.1870, c = −0.1139   (식50형 kRs = 0.1513)
예보 적용 시 강수유무는 PCP 예보로 판정
```

**하늘상태 반영 S4 (G3 재검증, 2026-09-29 채택)** — 기온교차와 강수유무로는 구름을 다 알 수 없어 여름 Rs를 적게 추정했습니다(아래 H2 결과). 단기예보의 하늘상태(SKY: 맑음·구름많음·흐림)를 더합니다.
강수 입력은 처음에 강수유무였고, 2025년 독립 검증과 자료 출처 대조 뒤 **강수확률 하루 최대**로 바꿨습니다(#17, 2026-09-30, 아래 ◆ 결정 반영).

```
Rs / Ra = a + b × √(Tmax − Tmin) + c × 강수확률(하루 최대, 0~1) + d × 구름많음 비율 + e × 흐림 비율   (선행일 k마다 a~e)

구름 비율 : 하루 하늘상태 예보를 낮 시간 일사 비중으로 가중한 비율(0~1)
           가중치 = 그 시각 태양고도의 사인값(밤 0). 태양시 = 시각 + (경도 − 135)/15 + 균시차[식32]
           → 일사가 많은 한낮의 하늘상태가 크게 반영됨
계수     : '예보 입력 → 관측 Rs' 최소제곱 (관측 운량이 없으므로). 예보 입력의 계통오차도 함께 흡수
           선행일마다 따로 맞춤: 먼 날의 하늘상태 예보일수록 덜 믿을 만하므로
           춘천 2026(운영 계수, rs_sky_coef.csv — OpenAPI 자료, 대상일 4/1~9/28, #14):
                    흐림 계수 e = −0.24(D+0) → −0.16~−0.18(D+2~D+4)
                    강수확률 계수 c = −0.06(D+0) → −0.21~−0.22(D+2~D+4)
검증     : 월 단위 교차검증 — 대상월의 행에는 그 달을 뺀 나머지 달로 맞춘 계수를 씀
운영     : 한 생육기 전체로 맞춘 계수(rs_sky_coef.csv). 다른 해(2025) 독립 검증 완료(#13·#17·#14)
```

- 계수를 정한 자료로 성능까지 채점하면 실제보다 좋게 나옵니다. 그래서 반드시 **교차검증**으로 성능을 확인합니다. 교차검증은 계수를 맞출 때 쓰지 않은 기간으로 채점하는 방법이며, 사전검증에서는 한 달씩 빼고 맞춘 뒤 그 달을 예측했습니다.
- S3 계수는 다른 해(2025) 관측으로 정했지만, S4 계수는 같은 해(2026)의 다른 달로 정했습니다. 같은 해 안의 교차검증이므로 다른 해 자료로 한 번 더 확인했습니다(2025년 독립 검증, 아래).
- **FAO-56 권고:** 추정 Rs로 계산한 ETo는 하루 값보다 **여러 날의 합계·평균으로 쓰는 것**이 좋습니다. 그래서 서비스의 주 지표는 3일 누적 ETc로 합니다.

### ◆ 두 층위의 오차와 검증 설계

```
예보 ETo 오차 = ① 구조오차 : 예보에 없는 Rs를 추정해서 생기는 오차
             + ② 예보오차 : 기온·습도·풍속·강수 예보가 틀려서 생기는 오차
                            (선행시간이 길수록 커짐)
             + ③ 대표성 오차 : 격자 예보와 지점 관측의 공간 차이 (아래 ◇ 참고)
```

| 가설 | 검증 대상 | 방법 | 합격 기준 (2026-09-29 확정) |
| :--- | :--- | :--- | :--- |
| H1 구조 | ① | 관측값으로 '완벽한 예보'를 흉내내고(perfect-prognosis) Rs만 추정 | 생육기 RMSE ≤ 0.6 mm/일, 합계오차 ±5% |
| H2 예보 | ① + ② + ③ | 과거 단기예보(ASOS 101 격자, 02·17시 발표) vs ASOS 101 관측 ETo, 선행시간별 (아침 D0~D+3, 저녁 D+1~D+4) | D+1~D+3 모두 지속성 대비 RMSE 30% 이상 개선, D+1 RMSE ≤ 1.0 mm/일 |
| H3 운영 | 수집 안정성 | 정시 수집 성공률·결측률 | 성공 ≥ 99%, 실패 시 백업 자동 전환 |

**지표**
- RMSE: 평균적인 오차 크기
- MBE: 편향 (+이면 과대추정)
- R²
- 합계오차: 기간 합계의 상대오차
- 3일 누적 RMSE

**기준선**
- 지속성: 발표 시점에 알 수 있는 가장 최근의 완결된 관측일(발표일 전날) 값이 k일 뒤에도 같다고 가정
  - 02시에는 전날 ASOS 일자료가 아직 공개되지 않았을 수 있습니다. 따라서 이 가정은 실제 운영보다 기준선에 유리하고, 예보 판정에는 보수적입니다.
- 7일평균: 발표일 전 7일(D−7~D−1) 평균을 그대로 사용

예보가 이 기준선보다 나아야 예보를 쓸 의미가 있습니다.
- 개선율 = 1 − RMSE_예보 ÷ RMSE_기준선 (0보다 크면 기준선보다 좋음)

### ◇ 격자 예보를 지점에 적용할 때 주의점

1. **공간 대표성:** 예보는 5 km 격자의 대표값이고, 관측은 한 지점 값입니다. 둘의 차이(③)는 예보를 아무리 잘해도 남습니다.
   - 평균 편향은 지점별 보정으로 줄일 수 있지만, 날마다 달라지는 성분은 남습니다.
2. **격자는 좌표로 정합니다.** 읍면동 이름은 대표점(행정기관 위치 등)의 격자일 뿐입니다.
   - 넓은 면 지역은 농장이 다른 격자에 있을 수 있으므로, 농장은 좌표로 격자를 정합니다.
   - 격자표에 해당 격자의 읍면동이 없으면 포털에서 고를 수 없습니다. 예) 서산 ASOS 129 격자 (52,109) → API(nx, ny)로만 받을 수 있습니다.
   - 실제 예: 춘천 ASOS 101 격자(73_134)와 바로 옆 신북읍 격자(73_135)는 최고기온 예보가 평균 1.1℃ 달라, 예보 ETo가 0.16 mm/일 차이 났습니다(2026년 4~6월, 아래 ◆ 격자 비교).
3. **풍속:** 격자 풍속과 관측소 풍속(설치 환경·높이)이 다를 수 있습니다. ETo에 가장 민감한 입력이라(+1 m/s → +7.7%) 선행시간별 편향을 먼저 봅니다.
4. **기온 정의와 고도:**
   - 아침최저·낮최고와 0~24시 최저·최고의 정의 차이가 있습니다. 저녁에 찬 공기가 들어오는 날 등에 차이가 납니다.
   - 격자와 지점의 고도 차이는 기온 편향으로 나타납니다(기온 +1℃ → ETo +0.16 mm/일).
5. **발표 시점에 이미 지난 시각은 이전 발표로 채웁니다.** 02시 발표에는 오늘 00~02시 예보가 없습니다(API는 03시부터, 포털 과거자료는 08시부터).
   - 이 시각은 **그 이전의 가장 최근 발표 값**으로 채워 24시간을 맞춥니다. 포털 자료로 검증할 때 아침 D0의 00~07시는 전날 17·20·23시 발표 값입니다.
   - 발표 시점에 알 수 있던 정보만 쓰므로 검증이 공정합니다. (G0의 '21시간 평균' 안을 G1에서 이 규칙으로 바꿈)
   - 최저·최고기온은 02시 발표에 오늘 값이 들어 있습니다.
6. **마지막 날(아침 D+3, 저녁 D+4):** 3시간 간격이고 풍속·강수가 코드값입니다.
   - 춘천은 2026년 4/1~9/13 일평균 풍속이 최대 3.2 m/s라, 풍속은 거의 항상 코드 1(4 m/s 미만)입니다.
   - 코드에 정보가 없으므로 변환 규칙([ARCHITECTURE.md 7장](ARCHITECTURE.md))의 영향을 선행시간별로 따로 평가합니다.
7. **발표 시각:** 서비스와 같은 02·17시 발표만 검증에 씁니다. 다른 발표를 섞으면 성능이 부풀려집니다.
8. **천문 계산 좌표:** Ra·Rso·기압은 격자가 아니라 대상 지점(ASOS 101 또는 농장)의 위도·고도로 계산합니다.

- **전날 관측 조회:** 슬롯마다 D−1 ASOS 일자료가 조회되는지와 처음 조회된 시각을 기록합니다(조회 시각 점검 명령 `probe-asos`를 매시 실행해 잼). 관측이 늦어도 규칙 3으로 서비스가 나가므로 H3 판정에는 넣지 않고, 그때의 예보 물수지 오차를 아래 ◆에서 따로 봅니다.

**검증 설계**
- **검정하는 것(오프라인):** 수집기가 규칙대로 동작하는가. 2026년 과거 예보(OpenAPI)로 모의 API를 만들어 운영 경로를 그대로 재생합니다. 관측 지연(d)은 2025·2026년 두 해로 계산합니다.
  - (a) 장애가 없으면 운영 경로의 서비스 입력·전망이 검증 경로(G3·G4)와 같은가(E1)
  - (b) 제공 지연·서버 오류·시간 초과·잘린 응답·발표 누락·하늘상태 누락·인증 오류를 넣었을 때 규칙대로 재시도·백업하는가
  - (c) 수집 로그로 H3 지표를 맞게 세는가
  - (d) 전날 관측이 없을 때(규칙 3) 예보 물수지 오차가 얼마나 커지는가 — 두 해 자료로 계산
- **검정하지 못하는 것:** 실제 API의 정시 제공률·응답 시간, 전날 ASOS 일자료의 실제 조회 가능 시각. → 국내 인터넷에 연결된 컴퓨터에서 현장 시험으로 봅니다(공공데이터포털은 해외 접속이 불안정할 수 있음, 이 작업 공간에서는 접속 차단).

**오프라인 검증 결과** (자세한 기록은 [VALIDATION.md](VALIDATION.md) G5)
- (a) 장애 없는 재생(2026년 생육기 슬롯 364회): 모두 정시 성공, 하루 8회 발표를 모두 받음. 운영 경로의 서비스 입력·관측·예보 ETo·관수 전망이 검증 경로와 같음(차이 0)
- (b)(c) 장애 재생(2026년 6월 슬롯 60회): 지연·누락·서버 오류·잘린 응답·하늘상태 누락·인증 오류에서 60회 모두 규칙대로 처리. 24시간 넘게 받지 못한 2회만 '실패'. 로그 집계(정시 50회, 백업 자동 전환 8/10)가 주입한 장애와 같음
- (d) 전날 관측이 없을 때: 아래 ◆ 전날 관측이 없을 때

### ◆ 전날 관측이 없을 때 — 아침 02:10 (G5, 2026-09-30)

아침 02:10에 전날(D−1) ASOS 일자료가 아직 없으면, 예보 물수지의 출발에 D−1의 관측 ETc·강수를 쓸 수 없습니다. 조회 가능 시각은 현장 시험에서 재고(`probe-asos`), 여기서는 **늘 없다고 볼 때** 예보 물수지가 얼마나 나빠지는지를 두 해 자료로 쟀습니다(`cropwater_fcst.py wbverify --morning-obs-lag`, 무관수, 아침 발표).

- **참값**은 그대로 관측 Dr(D−1 끝)에서 출발합니다. 예보 경로만 관측 Dr(D−2 끝)에서 D−1을 예보로 진행합니다.
- **채움**: G4에서 구현한 규칙. D−1을 아침 D+0 예보로 채워 관측처럼 쓰고, 세 경로가 같은 출발에서 시작합니다.
- **범위**: G5 규칙. D−1을 예보 하루로 진행하고 세 경로가 D−1부터 갈라집니다(중심은 '채움'과 같음).

| 해 | 방식 | 예상 Dr RMSE (mm, D+0 · D+1 · D+2) | 출발 오차 RMSE (mm) | 사건 | 범위 사건 | 범위 적중 | 실제가 '빠르면'보다 앞 | 판정 기준 30~60 mm 범위 적중 (앞선 경우) |
| :---: | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 2026 | 관측 있음 (G4) | 7.0 · 10.5 · 13.2 | 0 | 21 | 28 | 100% | 0 | 96~100% (0) |
| 2026 | 채움 | 10.4 · 12.3 · 14.6 | 7.1 | 20 | 25 | **80%** | **4** | 80~88% (13) |
| 2026 | **범위** | 10.4 · 12.3 · 14.6 | 7.1 | 20 | 34 | **100%** | **0** | 97~100% (0) |
| 2025 | 관측 있음 (G4) | 8.3 · 12.2 · 13.1 | 0 | 7 | 8 | 100% | 0 | 93~100% (0) |
| 2025 | 채움 | 11.8 · 13.6 · 14.3 | 8.3 | 6 | 7 | **71%** | **2** | 71~84% (9) |
| 2025 | **범위** | 11.8 · 13.7 · 14.3 | 8.3 | 6 | 10 | **100%** | **0** | 94~100% (0) |

- **전날 관측이 없으면 중심 예상 Dr 오차가 D+0에서 3.4~3.5 mm, D+2에서 1.2~1.4 mm 커집니다.** 출발 오차(RMSE 7~8 mm)는 대부분 D−1 강수 예보에서 옵니다(가장 큰 날 37·74 mm). 관수 필요 판정 적중률(POD)은 0.85~0.90(2026)·0.76~0.83(2025)으로 조금 낮아집니다.
- **'채움'은 범위가 D−1의 불확실성을 담지 못합니다.** 실제 관수 필요일이 '빠르면'보다 앞선 경우가 4·2회 생기고, 판정 기준을 바꿔도 13·9회입니다. G4의 '범위가 실제 날짜를 담는다'는 성질이 깨집니다.
- **'범위'는 이 성질을 되살립니다**(두 해, 판정 기준 30~60 mm 모두 앞선 경우 0회). 대신 D−1 강수 예보가 있는 날은 범위가 넓어집니다(범위 사건 28 → 34회, 8 → 10회).
- 저녁 17:10에는 전날 관측이 있다고 봅니다(현장 시험의 조회 시각으로 확인). 없으면 같은 규칙으로 전날과 그날을 차례로 진행합니다(구현은 여러 날도 처리).
- **02:10에 전날 관측이 늘 없다면** 아침 서비스는 위 '범위' 성능이 됩니다. 이때는 다른 실시간 관측(기상청 API허브의 ASOS 시간자료 등)으로 전날 강수를 채우는 방안을 검토합니다(VALIDATION 후속 #21).

### ◆ 과습 표시와 날짜 조회 — 서비스 엑셀 (2026-10-02)

서비스 엑셀의 상태 칸은 관수 쪽(안전·주의·관수 필요)만 보여 주었습니다. 관수 기록을 넣은 2026-09-18 아침 엑셀에서 전날 끝 Dr이 0인데 '안전'으로 나와, 물이 넘치는 쪽도 표시하기로 했습니다(사용자 결정).

**물수지로 말할 수 있는 것**

- Dr = 0은 근권이 포장용수량까지 찬 상태입니다(식85·86). 이때 더 들어온 비·관수는 모두 심층침투 DP가 됩니다(식88).
- FAO-56 물수지는 포장용수량보다 젖은 상태를 다루지 않습니다. 넘친 물은 그날 안에 빠진다고 가정합니다. 실제 배수 속도, 배수 불량, 지하수위는 계산에 없습니다.
- 그래서 '과습'은 "근권이 가득 차 있어 지금 주는 물은 버려진다"는 뜻의 참고 지표입니다. 뿌리가 물에 잠겼다는 진단이 아닙니다.

**판정 기준**

| 상태 | 기준 (관측 물수지의 끝 Dr) | 뜻 |
| :--- | :--- | :--- |
| 과습 경고 | Dr = 0 (0.05 mm 미만) | 포장용수량까지 참. 그날 DP가 있었으면 넘친 것 |
| 과습 주의 | 0 < Dr ≤ 과습 주의 기준 (기본 RAW × 10% = 6 mm) | 가득 찬 뒤 하루 이틀 치 증발산만 빠짐. 작은 관수에도 다시 넘침 |
| 안전 · 주의 · 관수 필요 | 그 밖 (RAW의 50%·100% 경계) | 기존 규칙 |

- **예보는 쓰지 않습니다**(사용자 결정). 예보 강수량은 관측보다 1.1~2.1배 많아(◆ G4 검증 결과) 예보로 과습을 말하면 헛경보가 많습니다. 조회일 전날이 예보로 진행한 날이면 과습을 판정하지 않습니다.
- **전날 관측이 아직 없을 때**(아침 02:10)는 관측 마지막 날 끝 Dr로 판정하고 그 날짜를 함께 적습니다. 하루 지난 값이라 실제보다 젖은 쪽으로 나올 수 있습니다.
- **생육기(Kc > 0)에만** 판정합니다. 휴면기에는 ETc = 0이라 Dr이 내내 0이기 때문입니다.
- **과습 주의 기준 10%는 출발값입니다.** 9월 사과 ETc 약 3~4 mm/일로 1.5~2일 치입니다. 검증된 값이 아니며 설정 시트에서 바꿉니다.
- 참고(관수 기록을 넣은 2026-09-30 저녁 엑셀, 4~9월 183일): 끝 Dr = 0인 날 52일, 0 < Dr ≤ 6 mm인 날 32일. 장마철(7~8월)에 몰려 있습니다. 관수 기록에 따라 달라지는 값입니다.
- 관수 보류(관수 필요 예상일 가까이에 비 예보가 있을 때)는 '앞으로 3일'에 넣을 정보라 이번 범위에서 뺐습니다.

**날짜 조회**

- 조회일을 바꾸면 전날 끝 Dr과 그 뒤 3일을 다시 보여 줍니다. 지난 날짜는 관측 물수지 결과이고, 발표일 뒤는 이 발표의 예보입니다.
- 지난 날짜의 값은 실제 비와 관수 기록이 들어간 결과입니다. 그날 그 시각에 나갔던 예보 전망을 되살린 것이 아닙니다(지난 발표의 전망은 그 발표의 엑셀에 있음).
- 3일 누적 ± 오차(r₃)는 이 발표·이 선행일의 오차라 발표일 조회에만 붙입니다.
- 검증: 발표일 조회 값이 이전 양식과 같음(첨부 2개 엑셀, 차이 0). LibreOffice 재계산 오류 0, 조회일 8가지와 관측 지연·저녁 발표에서 Python 계산과 같음(단위테스트).

  - 서비스 엑셀은 월·발표·선행일별 예보 오차(±)를 함께 보여 줍니다(오차표, #18).

  - 관수 필요 예상일을 채점할 사건이 적습니다(RAW 60 mm, 주 지표: 발표별 2026년 20·21회, 2025년 6·7회 — 몇 번의 건조기를 여러 발표가 나눠 본 것). 판정 기준을 30~60 mm로 바꿔도 실제가 '빠르면'보다 앞선 경우는 0회, 범위 적중은 95~100%였습니다.

- **토양·작물 값은 대표값입니다.** TAW·RAW는 양토·Zr 1 m(사과), Kc는 FAO-56 표값·현지기상 보정입니다. 실제 농장의 토양수분 센서와 비교한 검증은 아직 없습니다(과제 실증 포장 자료로 다음 사이클).
- **운영 확인 사항(G5):** 아침 02:10에 전날 ASOS 일자료가 없으면 예보 물수지 오차가 커집니다(위 ◆ 전날 관측이 없을 때: D+0 7.0 → 10.4 mm). 실제 조회 가능 시각은 현장 시험에서 잽니다.
- **자료 공백:** 검증에서는 한 요소라도 빠진 발표를 뺐습니다. 운영(G5)에서는 직전 발표로 대신하고, 하늘상태가 없으면 S3로 계산합니다(◆ 운영 수집). 규칙대로 동작하는지는 모의 재생으로 확인했고, 실제 정시 수집률(H3)은 현장 시험으로 판정합니다.
