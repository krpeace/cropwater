## 1. 왜 관수가 필요한가

토양수분이 부족해지면 식물에 **수분스트레스(water stress)**가 발생합니다.

| 스트레스 반응 | 결과 |
| :--- | :--- |
| 기공 닫힘 → 광합성 감소 | 생육 둔화 |
| 세포 팽압 저하 | 잎 시들음 |
| 과실 비대기 스트레스 | 수량 감소·품질 저하 (사과: 소과화, 배추: 구 형성 불량) |

관수의 목적은 **토양수분을 작물이 스트레스를 받지 않는 범위(Dr < RAW)로 유지**하는 것입니다.

## 2. 증발산

**증발산(ET, Evapotranspiration)** = 증발(E) + 증산(T)

```
증발 (Evaporation)  : 토양·수면에서의 직접 기화. 일사·바람·습도에 의해 결정
증산 (Transpiration): 식물이 뿌리로 흡수한 물을 기공으로 내보내는 현상.
                      기상 조건 + 작물 종류 + 생육단계에 의해 결정

단위: mm/day  (1mm = 1m²당 1L = 1ha당 10톤/day)
```

## 3. 기준증발산량 ETo — FAO-56 Penman-Monteith

작물마다 물 소비량을 직접 측정하는 대신, FAO-56은 **기준작물(잔디)** 기준의 ETo를 먼저 계산하고 작물별 보정계수(Kc)를 곱합니다.

### ◆ Penman-Monteith 방정식 [식(6)] — FAO-56 표준

```
        0.408 × Δ × (Rn - G) + γ × (900/(T+273)) × u2 × (es - ea)
ETo = ─────────────────────────────────────────────────────────────
                    Δ + γ × (1 + 0.34 × u2)
```

| 기호 | 이름 | 단위 | 의미 |
| :--- | :--- | :--- | :--- |
| Rn | 순복사량 | MJ/m²/day | 작물이 받는 실질 에너지 (증발 에너지 원) |
| G | 지중열유속 | MJ/m²/day | 땅속으로 전달되는 열 (일 단위 ≈ 0) |
| T | 일평균기온 | °C | 높을수록 포화증기압 증가 |
| u2 | 2m 풍속 | m/s | 수증기를 날려 증발 촉진 |
| es − ea | 증기압 결핍 | kPa | 공기의 건조도 (클수록 증발 왕성) |
| Δ | 포화증기압 곡선 기울기 | kPa/°C | 기온 변화에 따른 포화증기압 변화율 |
| γ | 건습계 상수 | kPa/°C | 기압에 의존 (고지대일수록 작음) |

**분자 두 항의 의미:**
- `Δ × (Rn - G)` → 복사 에너지에 의한 증발
- `γ × u2 × (es - ea)` → 건조·바람에 의한 대류 증발

### ◆ 기상청 ASOS 데이터 대응

| FAO-56 변수 | ASOS 필드 | 결측 시 처리 |
| :--- | :--- | :--- |
| Tmax, Tmin | `maxTa`, `minTa` | 필수 (결측일 제외) |
| u10 → u2 | `avgWs` | 식(47): u2 = u10 × 4.87/ln(67.8×10−5.42) |
| Rs (일사량) | `sumGsr` | 일조시간(`sumSsHr`)으로 Ångström 공식 추정 |
| ea (실제증기압) | `avgPv` × 0.1 kPa | 이슬점(`avgTd`) 또는 상대습도(`avgRhm`) 대체 |
| P (기압) | `avgPa` × 0.1 kPa | 해발고도로 추정: P = 101.3 × ((293−0.0065z)/293)^5.26 |

### ◆ 실제 계산 예시

```
춘천(ASOS 101), 2026-04-01
  Tmax=17.7°C, Tmin=5.2°C, RH=83.9%
  u10=1.0 m/s → u2=0.57 m/s, Rs=10.47 MJ/m²/day

  → ETo = 1.77 mm/day
  → 잔디밭 1m²당 1.77L/day 증발산
```

### ◇ 증발접시 방법 — 대안적 ETo 추정

ASOS에서는 대형증발접시 일증발량(`sumLrgEv`, mm/day)을 제공합니다. 증발접시 관측값(Epan)에 기후·위치 보정계수 Kp를 곱해 ETo를 추정합니다.

```
ETo_pan = Kp × Epan
```

**Kp 결정 인자 (FAO-56 Table 30, Allen-Pruitt 방법)**

| 인자 | 영향 |
| :--- | :--- |
| u2 (풍속) | 클수록 Kp 감소 (접시는 실제 작물보다 바람 영향 과다) |
| RH (습도) | 높을수록 Kp 증가 |
| 풍상거리(fetch) | 접시 주변 노출 상태 (기본값 100m) |

**PM 방법과의 비교**

| | ETo_PM | ETo_pan |
| :--- | :--- | :--- |
| 필요 데이터 | 기온·습도·풍속·일사량·기압 | 대형증발량(Epan)·풍속·습도 |
| 일사 결측 시 | Ångström 보정으로 대체 가능 | 영향 없음 |
| 정확도 | 국제 표준 (기준값) | PM 대비 ±10~20% 편차 가능 |
| CropWater 활용 | 주 계산값 | 크로스체크·검증용 |

> **실용 포인트:** cropwater_multi.py의 `지점비교` 시트에서 pan/PM 비율이 0.7~0.8 범위에 있으면 두 방법이 수렴하는 것으로, 일사 데이터 신뢰도가 높다는 신호입니다. 비율이 이 범위를 크게 벗어나면 일사 또는 증발량 데이터 품질을 재확인해야 합니다.

## 4. 작물계수 Kc와 작물증발산량 ETc

```
ETc = Kc × ETo
```

- `Kc = 1.0`: 잔디와 동일한 물 소비
- `Kc > 1.0`: 잔디보다 많이 소비 (사과 중기: Kc ≈ 1.2)
- `Kc < 1.0`: 잔디보다 적게 소비 (발아 초기·수확기)

### ◆ 생육단계별 Kc 변화

```
Kc
 │
1.2 ─────────────────────── Kc_mid (중기)
 │                       ╱─────────╲
 │                     ╱             ╲─── Kc_end (후기)
0.7 ─── Kc_ini ───╱
(초기)   (발육기)   (중기)          (후기)
  L_ini    L_dev    L_mid            L_late
```

사과 (FAO-56 Table 12, 초생재배·동해 지역):

| 생육단계 | 기간 (일) | Kc | 시기 |
| :--- | :---: | :---: | :--- |
| 초기 (ini) | 20 | 0.50 | 발아~착엽 초기 |
| 발육기 (dev) | 70 | 0.50 → 1.20 | 잎 전개·생장 왕성 |
| 중기 (mid) | 90 | 1.20 | 과실 비대기 |
| 후기 (late) | 30 | 1.20 → 0.95 | 성숙·수확기 |

> 봄철(4~5월)은 Kc가 낮지만 ETo가 빠르게 올라가는 시기입니다. `ETc = 낮은 Kc × 높아지는 ETo` 구조여서 실제 물 수요는 무시할 수 없습니다.

### ◇ 현지기상 보정 [식(62)·(65)] — 선택적 보정

```
Kc_mid_adj = Kc_mid_tab + [0.04×(u2−2) − 0.004×(RHmin−45)] × (h/3)^0.3
```

- `u2`: 생육 중기 평균 2m 풍속
- `RHmin`: 생육 중기 평균 최저상대습도 (%)
- `h`: 작물 키 (m)
- **Kc_end > 0.45인 경우에만 적용**

## 5. 토양수분과 물 저장

토양의 물 저장을 **양동이**로 이해하면 직관적입니다.

```
지표면
 ─────────────────────────────────── ← 물이 넘치면 지표유출(RO)
 │                                 │
 │  ── 포장용수량(FC) ──           │ ← 중력배수 완료 후 수분 상한
 │                                 │
 │  ← 이 범위가 TAW (총유효수분) → │
 │                                 │
 │  ── 영구위조점(WP) ──           │ ← 이 아래는 뿌리 흡수 불가
 │                                 │
 ─────────────────────────────────── ← 근권 하단 (심층침투DP 경계)
```

### ◆ 주요 파라미터

**포장용수량 FC (Field Capacity)**
중력배수가 완료된 상태의 토양수분 함량. 작물 이용 가능 수분의 상한선.

**영구위조점 WP (Wilting Point)**
작물이 더 이상 물을 흡수할 수 없어 영구적으로 시드는 수분 함량.

**총유효수분 TAW [식(82)]**
```
TAW = 1000 × (FC − WP) × Zr   (mm)

예시: 양토, 사과(Zr=1.0m)
  TAW = 1000 × (0.22 − 0.10) × 1.0 = 120mm
  → ETc 5mm/day 기준 24일치 저장량
```

**쉽게이용가능수분 RAW [식(83)]**
```
RAW = p × TAW   (mm)

p = 고갈계수 (FAO-56 Table 22): 사과 0.50, 배추 0.45

예시: 사과, 양토
  RAW = 0.50 × 120 = 60mm
  → Dr이 60mm를 초과하면 수분스트레스 시작
```

### ◆ RAW·Dr 관계 도해

**① 토양 수분 상태 단면도**

```
 FC ────────────────────────────── 0mm ← Dr 기준점(포장용수량 = 고갈 없음)
 │                                 │
 │   ← RAW = 60mm →               │ Dr < RAW: 작물 무스트레스, 관수 불필요
 │                                 │
 RAW ─────────────────────────── 60mm ← Dr = RAW: 관수 트리거 지점 (●)
 │                                 │
 │   ← TAW − RAW = 60mm →         │ Dr > RAW: Ks < 1, 수분스트레스 진행
 │                                 │
 WP ─────────────────────────── 120mm ← Dr = TAW: 완전 고갈 (고사 위험)
```

> Dr(Root zone **D**epletion)은 **포장용수량(FC)에서 현재 수분이 얼마나 빠졌는가**를 나타냅니다.  
> Dr = 0이면 토양이 꽉 찬 상태, Dr = TAW이면 완전 고갈 상태입니다.

**② 일별 Dr 변화 흐름**

```
전일 Dr(i-1)
      │
      ├─ 강수 P가 있으면 → Dr 감소 (토양에 물이 채워짐)
      │     ├─ P > Dr(i-1) → 초과분은 심층침투(DP)로 손실
      │     └─ P ≤ Dr(i-1) → P만큼 Dr 감소
      │
      ├─ ETc_adj만큼 → Dr 증가 (작물이 물을 소비)
      │     └─ Dr > RAW이면 Ks < 1, ETc_adj = Ks × ETc (소비 둔화)
      │
      └─ 당일 Dr(i) 확정 (0 ≤ Dr ≤ TAW)
             │
             ├─ Dr < RAW  → 안전 (관수 불필요)
             └─ Dr ≥ RAW  → 관수 필요 ●
```

**③ 5월 건조기 실제 Dr 추이 예시 (사과, TAW=120, RAW=60)**

```
날짜  강수  ETc  Dr    상태
5/1   0    4.2  4.2   ░░░░░░░░░░░░░░░░░░░░░ 4mm  [안전]
5/5   0    5.0  21.8  ░░░░░░░░░░░░░░░░░░░░░ 22mm [안전]
5/10  0    5.1  47.4  ░░░░░░░░░░░░░░░░░░░░░ 47mm [주의: RAW 임박]
5/17  0    4.8  67.7  ░░░░░░░░░░░░▓▓▓▓▓▓▓▓ 68mm [● 관수 필요!]
5/20 55.5  2.7  24.6  ░░░░░░░░░░░░░░░░░░░░░ 25mm [강수로 회복]

      ← RAW=60mm →|← 스트레스 구간 →
```

### ◆ 토성별 유효수분보유량 (AWC)

| 토성 | FC (m³/m³) | WP (m³/m³) | AWC (mm/m) |
| :--- | :---: | :---: | :---: |
| 사양토 | 0.14 | 0.06 | 80 |
| 양토 | 0.22 | 0.10 | 120 |
| 식양토 | 0.30 | 0.15 | 150 |
| 식토 | 0.36 | 0.20 | 160 |

## 6. 일별 근권 물수지

### ◆ 물수지 방정식 [식(85)]

```
Dr(i) = Dr(i−1) − P(i) + ETc_adj(i) + DP(i)    (0 ≤ Dr ≤ TAW)

Dr(i)   : i일 말 근권 고갈량 (mm)
P(i)    : i일 강수량 (mm)
ETc_adj : 수분스트레스 보정 후 실제 증발산량
DP(i)   : 심층침투량 (mm)
```

### ◆ 수분스트레스계수 Ks [식(84)]

Dr이 RAW를 초과하면 작물의 실제 증발산이 감소합니다.

```
Dr ≤ RAW :  Ks = 1.0
Dr > RAW :  Ks = (TAW − Dr) / (TAW − RAW)

ETc_adj = Ks × ETc
```

예시 (TAW=120, RAW=60):

| Dr (mm) | Ks | 의미 |
| :---: | :---: | :--- |
| 30 | 1.00 | 무스트레스 |
| 60 | 1.00 | 경계 |
| 90 | 0.50 | 증발산 50%로 감소 |
| 120 | 0.00 | 완전 고갈 (고사 위험) |

### ◆ 심층침투 DP [식(88)]

```
DP(i) = max(P(i) − Dr(i−1), 0)
```

Dr=20mm 상태에서 50mm 비가 오면:
- DP = 50 − 20 = **30mm 손실**
- 근권 기여분 = **20mm** (고갈량 보충)

### ◆ 일별 추적 예시 (사과, 5월 건조기)

```
날짜   강수  ETc   Dr(전)  DP    Dr(후)  Ks    비고
5/1    0    4.2   0.0    0.0   4.2    1.00
5/5    0    5.0   16.8   0.0   21.8   1.00
5/10   0    5.1   42.3   0.0   47.4   1.00
5/17   0    4.8   62.9   0.0   67.7   0.88  ← Dr > RAW=60, 스트레스 시작
5/20  55.5  2.7   80.1   0.0   24.6   0.00  ← 강수로 Dr 회복
5/21   0    4.5   24.6   0.0   29.1   1.00  ← 스트레스 해소
```

> 같은 기간을 월별로 집계하면 "ΣP=0, ΣETc≈75mm → 부족 75mm"로만 나타납니다. 5/17 스트레스 시작 **시점**은 월별 집계로 포착할 수 없습니다.

## 7. 유효강수량 — 비가 와도 다 못 쓰는 이유

강수량 전체가 작물에 기여하지 않습니다. 손실 경로는 세 가지입니다.

| 손실 경로 | 발생 조건 |
| :--- | :--- |
| 지표유출 (RO) | 강우강도 > 토양 침투속도 |
| 심층침투 (DP) | 강수량 > 현재 고갈량 Dr |
| 차단손실 | 잎·줄기 표면에 맺혀 증발 |

**일별 유효강수 = min(강수량, Dr)**

Dr=20mm 상태에서 100mm 비 → 근권 흡수 20mm, 나머지 80mm 심층침투 손실.

**한국 여름 집중호우의 함정:**

```
7월 월강수량 350mm
  USDA SCS 월별 추정: Peff ≈ 160mm (유효율 46%)
  실제 (장마 집중호우 300mm×2회, TAW=60mm):
    1회당 흡수 가능 최대량 = 60mm → 실제 유효강수 ≈ 120mm (유효율 34%)
```

월별 집계는 집중호우 손실을 구조적으로 과소평가합니다. 이것이 이 프로그램이 **일별 Dr 추적**을 사용하는 이유입니다.

## 8. 한국 기후 특성과 관수 전략

### ◆ 월별 ETo·강수 패턴 (중부 내륙 기준)

```
월    강수(mm)  ETo(mm)  관수 필요성
1     20        25       낮음 (동계 휴면)
2     28        35       낮음
3     42        65       낮음~보통
4     68        95       ★ 높음 (봄 가뭄)
5     91       115       ★★ 매우 높음 (개화기·세포분열기)
6    133       125       보통 (장마 전)
7    370       130       낮음 (장마기, 단 집중호우→DP 주의)
8    270       125       보통~높음 (태풍 후 건조)
9    145        90       보통
10    52        55       낮음
```

### ◆ 임계 관수 시기

**사과 (4~5월)** — 개화기(4월 하순)~세포분열기(5월)의 Dr > RAW는 착과율·과실 크기에 직접 영향.

**배추 (7~8월)** — 결구 형성기 스트레스 → 구 불량·팁번(Tip-burn). 태백 고지대는 7월 하순~8월 초 건조기가 반복됨.

### ◆ 관수 판단 기준

| Dr 범위 | 판단 | 대응 |
| :--- | :--- | :--- |
| Dr < RAW × 0.5 | 안전 | 관수 불필요 |
| RAW × 0.5 ≤ Dr < RAW | 주의 | 3~5일 내 관수 계획 |
| Dr ≥ RAW | 관수 필요 ● | 즉시 관수 |
| Dr ≥ TAW × 0.7 | 긴급 | Ks < 0.5, 심각한 스트레스 |

### ◆ 관수량 계산

```
순관수량 In = Dr          (근권을 FC까지 보충하는 양)
총관수량 Ig = In / Ea     (손실 포함 실제 공급량)

Ea = 관수효율
  점적관수   : 0.90~0.95
  스프링클러 : 0.75~0.85
  도랑관개   : 0.40~0.60
```

## 9. 용어 정리

| 한국어 | 영문 | 약어 | 설명 |
| :--- | :--- | :---: | :--- |
| 증발산량 | Evapotranspiration | ET | 증발 + 증산 합계 |
| 기준증발산량 | Reference ET | ETo | 잔디 기준 ET |
| 작물증발산량 | Crop ET | ETc | Kc × ETo |
| 작물계수 | Crop coefficient | Kc | 작물별 물 소비 보정 비율 |
| 총유효수분 | Total Available Water | TAW | FC와 WP 사이의 저장 가능 수분량 |
| 쉽게이용가능수분 | Readily Available Water | RAW | 스트레스 없이 작물이 쓸 수 있는 수분 |
| 근권 고갈량 | Root zone depletion | Dr | FC 대비 현재 부족량 |
| 수분스트레스계수 | Water stress coefficient | Ks | 0~1, 1=무스트레스 |
| 심층침투 | Deep percolation | DP | 근권 아래로 손실된 물 |
| 포장용수량 | Field capacity | FC | 중력배수 완료 후 수분 함량 |
| 영구위조점 | Wilting point | WP | 식물 흡수 하한선 |
| 근권심도 | Root zone depth | Zr | 뿌리가 분포하는 깊이 (m) |
| 고갈계수 | Depletion fraction | p | RAW = p × TAW |
| 관수효율 | Application efficiency | Ea | 실제 근권 도달 비율 |
| 순관수량 | Net irrigation depth | In | 근권 보충 필요량 |
| 총관수량 | Gross irrigation depth | Ig | In / Ea |
